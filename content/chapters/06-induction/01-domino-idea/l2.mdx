You did not push a hundred dominoes. You pushed **one**. But you set things up so that each one would take care of the next.

That idea has a name in mathematics, and it is one of the most powerful tools there is.

## The two jobs

For the whole line to fall, two things must be true:

1. **The first one falls.** Somebody has to push it.
2. **Each one knocks over the next.** No gaps.

If either fails, the line does not all fall.

## Using it on a real claim

Here is something to be sure about.

> Whatever tower I can build, I can build one that is one block taller.

Can I build a tower of a hundred blocks? Let's use the dominoes.

**Job one.** Can I build a tower of $1$ block? Yes! Put a block down. Done.

**Job two.** If I have built a tower of *some* height, can I build one taller? Yes — put one more block on top.

Both jobs done. So I can build a tower of $2$, and therefore of $3$, and therefore of $4$... all the way to a hundred and beyond.

I never built a hundred-block tower to find out. The two jobs did it for me.

## Spotting a pattern is not the same as knowing

Here is something important, and it catches people out.

Suppose you add up odd numbers:

$1 = 1$

$1 + 3 = 4$

$1 + 3 + 5 = 9$

$1 + 3 + 5 + 7 = 16$

Those are $1, 4, 9, 16$ — the square numbers! It certainly looks like a pattern.

But looking is not knowing. You checked four cases. There are infinitely many. What if it breaks at the fiftieth one? Or the millionth?

The dominoes are how you find out for certain, and module 6.2 shows exactly how.

<Warning title="A pattern can hold for ages and then break">
Grown-up mathematicians have found patterns that held true for the first forty numbers, and then failed. And some that held for millions of numbers before failing.

So checking cases is a great way to *guess*. It is never a way to *know*.
</Warning>

<Aside>
This is called *induction*, and once you learn it you will see it everywhere — in number puzzles, in computer programs, and in almost every branch of mathematics.
</Aside>
