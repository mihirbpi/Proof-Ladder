Get some square tiles. Or blocks. Or crackers!

Put down **1** tile. Is that a square? Yes! A tiny one.

Now add **3** more, in an L-shape around two sides.

Count them all. **4** tiles. And look — a bigger square!

Now add **5** more, in a bigger L-shape.

Count. **9** tiles. Square again!

Now add **7** more.

**16** tiles. Still square!

<Figure alt="A 4 by 4 square of dots built from four nested L-shaped shells holding 1, 3, 5 and 7 dots.">
  <LShells n={4} />
</Figure>

Every time you add the next **shell**, you get the next square.

$1$, then $3$, then $5$, then $7$. Odd numbers, every time. And squares, every time.

<TryIt>
Use 16 crackers. Build the 1, then the 4, then the 9, then the 16. Say each shell size out loud as you add it.
</TryIt>
