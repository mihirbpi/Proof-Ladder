Dominoes only work if they are **in a line**.

One, then the next, then the next. Each one has a neighbor to knock over.

Now put your dominoes in a big scattered pile instead.

Push one. What happens?

Almost nothing! It bumps whatever is next to it, and then it stops. No chain.

<DominoRow count={6} fallen={3} gapAfter={2} pushed={true} />

There is no line, so there is no chain.

Some things in the world come in a line. First, second, third, fourth — you can count them.

Some things do not. All the water in a puddle is not in a line. You cannot say which drop is first.

Dominoes only help with the lined-up ones.
