Induction requires two things, and both are substantive.

## Requirement 1: an integer index

The claim must have the form $\forall n \geq n_0,\ A(n)$ with $n$ ranging over integers. Without a discrete index there is no successor, hence no step.

$$\forall x \in \mathbb{R},\ x^2 \geq 0$$

is **not** an induction candidate. $\mathbb{R}$ has no successor function: by density (module 4.6), no real has a next real. The claim is true and is proved by the arbitrary-element method with a case split on sign (module 1.12).

<Warning title="Real-indexed claims sometimes hide an integer">
$\forall x \in \mathbb{R},\ (1+x)^n \geq 1+nx$ for $x \geq -1$ — Bernoulli's inequality — *is* provable by induction, because the induction runs on $n$ with $x$ held fixed as an arbitrary parameter.

So the question is not whether real variables appear, but whether some **integer** variable indexes the family of statements.
</Warning>

## Requirement 2: a link from $k$ to $k+1$

Knowing $A(k)$ must materially assist in proving $A(k+1)$. Countability of cases is not enough.

$$\forall n \geq 1,\ p_n \text{ is odd} \quad (p_n = \text{the } n\text{th prime})$$

has an integer index, so Requirement 1 holds. But $p_{k+1}$ is not built from $p_k$ by any usable rule, so assuming $A(k)$ gives no traction. (The claim also fails at $n=1$, but even repaired, induction is not the method.)

### Where links come from

Compare with the standard sources of a link, all of which are recursive constructions:

| Object | Link |
|---|---|
| a running total $a_1 + \cdots + a_n$ | the next total is this total plus one more term |
| a running product $a_1 \cdots a_n$ | the next product is this product times one more factor |
| $a^n$ | $a^{n+1} = a\cdot a^n$ |
| $n!$ | $(n+1)! = (n+1)\cdot n!$ |
| $f^{(n)}$ | $f^{(n+1)} = (f^{(n)})'$ |
| $\lvert S\rvert = n+1$ | remove an element to get $\lvert S'\rvert = n$ |

**If the object is defined recursively, induction is almost certainly the right tool** — and Chapter 7 makes this precise by defining $+$ and $\times$ recursively and proving their properties by induction.

## When the immediate predecessor is not enough

Sometimes $A(k+1)$ depends on earlier cases, not on $A(k)$.

> **Every integer $n \geq 2$ has a prime factorisation.**

If $n+1$ is prime, done. Otherwise $n+1 = ab$ with $2 \leq a, b \leq n$ — and $a$, $b$ may be far below $n$. Assuming only $A(n)$ is useless.

**Strong induction** repairs this: assume $A(n_0), A(n_0+1), \ldots, A(k)$ and prove $A(k+1)$.

<Proof title="Strong induction is ordinary induction">
Given $A$, define $B(n) := A(n_0)\wedge A(n_0+1)\wedge\cdots\wedge A(n)$.

The strong-induction hypothesis for $A$ is exactly $B(k)$, and $B(k) \Rightarrow A(k+1)$ gives $B(k) \Rightarrow B(k+1)$. So ordinary induction applies to $B$, yielding $B(n)$ — hence $A(n)$ — for all $n$.
</Proof>

So strong induction is not a new axiom, only a convenient repackaging. Use it when the decomposition of $n+1$ is not into $n$.

## A checklist

Before attempting an induction:

1. **Is there an integer index?** If not, use module 1.12's methods.
2. **Compute several cases.** Both to find the correct statement and to avoid proving something false (module 6.1).
3. **Can I express the $(k+1)$-object in terms of the $k$-object?** Write that expression down before starting — it will be the first line of the step.
4. **Ordinary or strong?** Does $A(k+1)$ need only $A(k)$, or earlier cases too?
5. **Where does it start?** $2^n > n^2$ needs $n_0 = 5$.

<Aside>
Induction generalises beyond $\mathbb{N}$. **Structural induction** proves statements about recursively defined objects — expressions, trees, formulas — by handling each constructor. To prove every well-formed formula has balanced parentheses, one checks the atomic case and each way of building bigger formulas from smaller.

This is the form used constantly in computer science, and it is the same principle: the objects are built in stages, so a property that survives each construction step holds throughout.
</Aside>
