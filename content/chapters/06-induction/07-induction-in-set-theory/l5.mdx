## The power set

For a set $S$, the **power set** $\mathcal{P}(S)$ is the set of all subsets of $S$.

$$
\mathcal{P}(\{a,b\}) = \big\{\ \emptyset,\ \{a\},\ \{b\},\ \{a,b\}\ \big\}.
$$

*Symbol by symbol: $\emptyset$ is the empty collection.*

Four elements, and each is itself a set — module 2.1's observation that sets can contain sets, now put to work.

Note that $\emptyset$ and $S$ are always members, since $\emptyset \subseteq S$ and $S \subseteq S$ (module 2.3).

## Counting

| $|S|$ | subsets | $|\mathcal{P}(S)|$ |
|---|---|---|
| $0$ | $\emptyset$ | $1$ |
| $1$ | $\emptyset, \{a\}$ | $2$ |
| $2$ | $\emptyset,\{a\},\{b\},\{a,b\}$ | $4$ |
| $3$ | — | $8$ |

**Conjecture:** $|\mathcal{P}(S)| = 2^{|S|}$ for finite $S$.

The doubling is visible in the construction. Going from $\{a,b\}$ to $\{a,b,c\}$, every old subset is still a subset, and every old subset with $c$ added is a new one. Old plus new is twice as many — and that observation is the inductive step in disguise.

## The proof

<Discussion>
  <div slot="know">$A(k)$: every $k$-element set has $2^k$ subsets. Available: bijections as the way to compare sizes (module 3.8).</div>
  <div slot="want">Every $(k+1)$-element set has $2^{k+1}$ subsets.</div>
  <div slot="how">Remove one element $a$, leaving a $k$-set the hypothesis applies to. Then split the subsets of the big set by whether they contain $a$, and match the two groups.</div>
</Discussion>

<Proof>
Let $A(n)$ be: *every set with $n$ elements has exactly $2^n$ subsets*, for $n \geq 0$.

**Base case.** $A(0)$: the only set with $0$ elements is $\emptyset$, whose only subset is $\emptyset$ itself. So it has $1 = 2^0$ subsets ✓

**Inductive step.** Let $k \geq 0$ and assume $A(k)$. Let $S$ have $k+1$ elements, and fix $a \in S$. Then $S \setminus \{a\}$ has $k$ elements.

Split the subsets of $S$ into two groups.

*Group 1: those not containing $a$.* These are exactly the subsets of $S\setminus\{a\}$, so by $A(k)$ there are $2^k$ of them.

*Group 2: those containing $a$.* Each has the form $T \cup \{a\}$ for exactly one $T \subseteq S\setminus\{a\}$.

Consider the map $T \mapsto T \cup \{a\}$, where the arrow $\mapsto$ is read *"maps to"* and names a function by what it does to a typical input. It is a bijection from Group 1 to Group 2: injective because $T$ is recovered by removing $a$, and surjective because every subset containing $a$ arises this way. So Group 2 also has $2^k$ members.

The groups are disjoint and together contain every subset, so
$$
|\mathcal{P}(S)| = 2^k + 2^k = 2^{k+1},
$$
which is $A(k+1)$.

By induction, $|\mathcal{P}(S)| = 2^{|S|}$ for every finite set $S$.
</Proof>

**Three earlier ideas were used**: the inductive hypothesis, a bijection to show two groups have equal size (module 3.8), and the fact that disjoint groups covering everything can be counted by adding (module 2.4).

<Warning title="Disjoint and exhaustive">
The final addition needs both conditions, and both were checked.

**Disjoint:** no subset is in both groups, since a subset either contains $a$ or does not — never both. Module 1.3's excluded middle.

**Exhaustive:** every subset is in one group, for the same reason.

Adding the counts of overlapping groups double-counts; adding the counts of groups with a gap undercounts. Neither check is automatic, and module 4.4 made the same demand of case splits.
</Warning>

## A second proof, without induction

Build a subset by walking through the elements of $S$ and deciding, for each one, whether to include it.

That is $|S|$ independent yes/no choices, each with $2$ options, so the number of ways is
$$
\underbrace{2\times2\times\cdots\times2}_{|S| \text{ times}} = 2^{|S|}.
$$

Different choice-sequences give different subsets, and every subset arises from one — so this is a bijection between $\mathcal{P}(S)$ and the sequences of $|S|$ yes-or-no choices.

**Shorter, and it explains the $2$.** The base is $2$ because each element faces two options, which the induction proof never quite says.

<Aside>
Two proofs of one theorem, and neither is redundant.

The induction **verifies**: given the pattern, it confirms the formula, mechanically.

The counting argument **explains**: it says why $2$, and why a power, in a way that would let you predict the answer to a variant. Change each element's choice from two options to three and the counting argument immediately gives $3^{|S|}$, while the induction would have to be rewritten.

Mathematicians collect proofs of the same theorem for exactly this reason, and it is usually the explanatory one that generalises.
</Aside>

## Beyond the finite

For infinite $S$ the formula has no meaning as written. The underlying comparison still does.

> **Cantor's theorem.** For every set $S$, no function $S \to \mathcal{P}(S)$ is surjective.

So $\mathcal{P}(S)$ is strictly larger than $S$ — always, including when $S$ is infinite. Applying it to $\mathbb{N}$ gives an infinite set strictly bigger than $\mathbb{N}$; applying it again gives a bigger one still.

**There is no largest infinity.** Module 3.8 found that $\mathbb{R}$ is bigger than $\mathbb{N}$; this says the tower continues forever.

Note what the induction could *not* do. It proved the finite case and stops there, because module 6.4's chain has no rung labelled *infinite*. The finite formula and the infinite theorem are genuinely different results, and only one of them is an induction.
