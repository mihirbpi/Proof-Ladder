The **power set** of $S$ is
$$
\mathcal{P}(S) = \{\, A \mid A \subseteq S \,\}.
$$

*Symbol by symbol: $\subseteq$ is "sits inside", the bar $\mid$ is "such that". So the line reads: the power set of $S$ is the collection of every set that sits inside $S$.*

Its elements are sets. For $S = \{a,b\}$:
$$
\mathcal{P}(S) = \big\{\, \emptyset,\ \{a\},\ \{b\},\ \{a,b\} \,\big\},
$$

*Symbol by symbol: $\emptyset$ is the empty collection. So the line reads: for a two-member set, that collection has four members: nothing, each single member on its own, and the whole thing.*

so $|\mathcal{P}(S)| = 4$.

> **Theorem.** If $|S| = n$ then $|\mathcal{P}(S)| = 2^n$.

## Proof by induction

<Discussion>
  <div slot="know">Every subset of $S$ either contains a fixed element $a$ or does not — excluded middle (module 1.3), giving an exhaustive and disjoint split.</div>
  <div slot="want">$|\mathcal{P}(S)| = 2^{k+1}$ for $|S| = k+1$, given the result for size $k$.</div>
  <div slot="how">Fix $a \in S$ and set $S' = S\setminus\{a\}$, of size $k$. Partition $\mathcal{P}(S)$ by membership of $a$. The subsets avoiding $a$ *are* $\mathcal{P}(S')$; the subsets containing $a$ are in bijection with $\mathcal{P}(S')$ by removing $a$ from each.</div>
</Discussion>

<Proof>
Let $A(n)$ be: every set of size $n$ has exactly $2^n$ subsets.

**Base.** $A(0)$: the only set of size $0$ is $\emptyset$, whose only subset is $\emptyset$. So $|\mathcal{P}(\emptyset)| = 1 = 2^0$. ✓

**Step.** Assume $A(k)$. Let $|S| = k+1$, fix $a \in S$, and put $S' = S\setminus\{a\}$, so $|S'| = k$.

Partition $\mathcal{P}(S)$ into
$$
\mathcal{U} = \{A \subseteq S : a \notin A\}, \qquad
\mathcal{V} = \{A \subseteq S : a \in A\}.
$$

*Symbol by symbol: $\subseteq$ is "sits inside", $\notin$ is "is not in", $\in$ is "is in". So the line reads: $\mathcal{U}$ holds the subsets that leave $a$ out; $\mathcal{V}$ holds the subsets that include it.*

These are disjoint and their union is $\mathcal{P}(S)$, since $a \in A$ or $a \notin A$ for each $A$.

*Counting $\mathcal{U}$.* $A \subseteq S$ with $a \notin A$ holds exactly when $A \subseteq S'$. So $\mathcal{U} = \mathcal{P}(S')$, and $|\mathcal{U}| = 2^k$ by (IH).

*Counting $\mathcal{V}$.* Define $u : \mathcal{V}\to\mathcal{P}(S')$ by $u(A) = A\setminus\{a\}$, and $v : \mathcal{P}(S')\to\mathcal{V}$ by $v(B) = B\cup\{a\}$. Then $u(v(B)) = B$ and $v(u(A)) = A$ for $A \in \mathcal{V}$, so $u$ is a bijection (module 3.9). So $|\mathcal{V}| = |\mathcal{P}(S')| = 2^k$.

Therefore
$$
|\mathcal{P}(S)| = |\mathcal{U}| + |\mathcal{V}| = 2^k + 2^k = 2^{k+1},
$$
establishing $A(k+1)$.
</Proof>

Note that the step used a **bijection** to transfer a count between two sets, rather than recounting. That is module 3.8's principle — same size means a bijection exists — doing real work.

## Proof by counting choices

<Proof title="Second proof">
Go through the elements of $S$ one at a time and answer **yes** or **no**: is this one in $A$?

That list of answers pins $A$ down completely — and every possible list of answers comes from exactly one subset, since you can read the subset back off as the elements you answered yes to. So subsets and answer-lists are matched one-for-one.

An answer-list is $n$ separate yes-or-no choices, each made without regard to the others: $2$ ways, $n$ times, so $2^n$ lists — and therefore $2^n$ subsets.

So $|\mathcal{P}(S)| = 2^n$.
</Proof>

This proof explains the notation $2^S$ for the power set: it is literally the set of functions from $S$ into a two-element set, and the exponential notation for function spaces makes the cardinality (size, §3.8) formula automatic.

<Warning title="The empty set and the whole set both count as subsets">
$\emptyset \in \mathcal{P}(S)$ and $S \in \mathcal{P}(S)$ always. Omitting either breaks the count immediately: without $\emptyset$ a two-element set would have $3$ subsets.

Watch the levels, too. For $S = \{a,b\}$: $a \in S$ but $a \notin \mathcal{P}(S)$; $\{a\} \subseteq S$ and $\{a\} \in \mathcal{P}(S)$. The elements of $\mathcal{P}(S)$ are sets, and module 2.3's $\in$-versus-$\subseteq$ distinction is what keeps this straight.
</Warning>

<Aside>
Notice where this proof stops. It settles every finite size, because module 6.4's chain has a rung for each counting number and the argument walks along them. A set with infinitely many elements is on no rung at all, so the induction says nothing about one.

That is not a defect in the proof. It is a real boundary: a set that never runs out has to be compared with something else by a different method entirely, and induction is not that method.
</Aside>
