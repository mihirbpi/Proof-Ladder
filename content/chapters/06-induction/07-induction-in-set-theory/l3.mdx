Chapter 2 gave you sets and subsets. This module counts them, and the count is a clean induction.

## Listing the subsets

Take $S = \{a, b\}$. What are its subsets?

$$
\{\,\}, \quad \{a\}, \quad \{b\}, \quad \{a,b\}.
$$

Four. Note that the empty set counts (module 2.3 proved it sits inside every set), and so does $S$ itself.

The set of all subsets of $S$ is called the **power set** of $S$.

Now do it for a few sizes.

| $|S|$ | subsets | how many |
|---|---|---|
| $0$ | $\{\,\}$ | $1$ |
| $1$ | $\{\,\}, \{a\}$ | $2$ |
| $2$ | $\{\,\},\{a\},\{b\},\{a,b\}$ | $4$ |
| $3$ | (eight of them) | $8$ |

$1, 2, 4, 8$ — doubling.

> **Claim.** A set with $n$ elements has $2^n$ subsets.

## Why it doubles

<Discussion>
  <div slot="know">Every subset either contains a chosen element or does not — and those are the only two options (module 1.3's excluded middle).</div>
  <div slot="want">The count for a set with one more thing in it, given the count for the smaller set.</div>
  <div slot="how">Pick one element $a$ out of the bigger set. Split the subsets into those containing $a$ and those not. Each group turns out to have exactly as many members as the power set of the elements that are left.</div>
</Discussion>

<Proof>
The claim, case by case: *a set with no elements has $1$ subset; a set with one element has $2$; a set with two has $4$;* and so on, doubling each time.

**Base case.** The only set with no elements is $\{\,\}$, and its only subset is $\{\,\}$ itself. So it has exactly $1$ subset. ✓

**Inductive step.** Suppose the claim holds for the case you are on — for sets of some particular size.

Now take a set with one more element than that. Pick one of its elements and call it the **new one**. Set the new one aside; what is left is a set of the size you already know about.

Now split the subsets of $S$ into two groups.

**Group 1: subsets that leave the new one out.** These are exactly the subsets of what was left when you set it aside. By the inductive hypothesis, you already know how many there are.

**Group 2: subsets that take the new one along.** Take any such subset and remove the new one — what is left is a subset of the smaller set. And going the other way, take any subset of the smaller set and drop the new one in. So the two groups pair up perfectly (module 3.8), and Group 2 has exactly as many members as Group 1.

Every subset is in exactly one group, and the two groups are the same size. So the total is **double** what it was for the smaller set.

That is exactly what the next case claims. Both conditions hold, so the claim is true for every case.
</Proof>

## A second proof, with no induction at all

Line up the elements. To build a subset, walk down the line and, for each one, decide **in** or **out**.

That is $2$ choices, $n$ times. So there are
$$
\underbrace{2 \times 2 \times \cdots \times 2}_{n} = 2^n
$$
subsets.

More precisely: a subset is the same thing as a function from $S$ to $\{\text{in}, \text{out}\}$ — a machine sending each element to one of two answers (Chapter 3). Counting subsets and counting those functions is the same job.

<Warning title="Do not forget the empty set and the whole set">
The two most-forgotten subsets are the empty one — the set with nothing in it — and the whole set. Both are genuine subsets (module 2.3), and both are needed for the count to come out to $2^n$.

Check: for $|S| = 2$ the answer is $4$. Omitting $\{\,\}$ gives $3$, and the doubling pattern dies immediately.
</Warning>

<Aside>
The notation for the power set is sometimes written $2^S$, and now you can see why: its size is $2^{|S|}$. The exponent notation is doing real work rather than being a coincidence.

The doubling continues without limit, and it does something remarkable for infinite sets too — a set always has strictly *more* subsets than elements, even when it is infinite. That is Cantor's theorem, and it is why there is no largest infinity.
</Aside>
