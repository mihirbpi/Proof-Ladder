> **Theorem.** For finite $S$ with $|S| = n$, $\ |\mathcal{P}(S)| = 2^n$.

## Inductive proof

<Discussion>
  <div slot="know">Membership of a fixed $a$ partitions $\mathcal{P}(S)$ into two blocks — an exhaustive, disjoint split by excluded middle (every statement is either true or false, §1.2).</div>
  <div slot="want">$|\mathcal{P}(S)| = 2^{k+1}$ when $|S|=k+1$.</div>
  <div slot="how">Remove $a$. Subsets avoiding $a$ *are* $\mathcal{P}(S\setminus\{a\})$; subsets containing $a$ biject with it via $A \mapsto A\setminus\{a\}$. Add the two counts.</div>
</Discussion>

<Proof>
*Base.* $|\mathcal{P}(\emptyset)| = |\{\emptyset\}| = 1 = 2^0$.

*Step.* Assume the result for sets of size $k$. Let $|S| = k+1$, fix $a \in S$, $S' = S\setminus\{a\}$.

Partition $\mathcal{P}(S) = \mathcal{U}\cup\mathcal{V}$ with $\mathcal{U} = \{A : a\notin A\}$, $\mathcal{V} = \{A : a \in A\}$.

$\mathcal{U} = \mathcal{P}(S')$, so $|\mathcal{U}| = 2^k$ by (IH).

$p : \mathcal{V}\to\mathcal{P}(S')$, $A \mapsto A\setminus\{a\}$, has two-sided inverse $B \mapsto B\cup\{a\}$, so is a bijection (§3.9); so $|\mathcal{V}| = 2^k$.

So $|\mathcal{P}(S)| = 2^k+2^k = 2^{k+1}$.
</Proof>

The step transferred a count along a bijection rather than recounting — §3.8's principle in use.

## Bijective proof

<Proof title="Second proof">
Take any subset $A$ of $S$ and record a yes-or-no answer at every element of $S$: **yes** if that element is in $A$, **no** if it is not.

That record pins $A$ down completely, and every possible record comes from exactly one subset — read the subset back off as the elements answered yes. So subsets and records are matched one-for-one.

A record is $n$ separate yes-or-no answers, each made independently of the others: $2$ ways, $n$ times, so $2^n$ records, and therefore $2^n$ subsets.
</Proof>

This is where the notation $2^S$ for the power set comes from: two choices at each element of $S$. And the match is better than a count. An element is in $A \cap B$ exactly when it answered yes on both records, and outside $A$ exactly when it answered no on that one — so the set operations of §2.7 correspond to operations on the records, not merely the totals.

<Warning title="Level discipline">
Elements of $\mathcal{P}(S)$ are *sets*. For $S = \{a,b\}$: $a \in S$, $\{a\}\in\mathcal{P}(S)$, $\{a\}\subseteq S$, $\{\{a\}\}\subseteq \mathcal{P}(S)$ — and $a \notin \mathcal{P}(S)$.

Both $\emptyset$ and $S$ belong to $\mathcal{P}(S)$; omitting either destroys the count. And $\mathcal{P}(\emptyset) = \{\emptyset\}$ has one element, not zero — the distinction §2.1 insisted on.
</Warning>

## Refinement by size

Splitting by cardinality (size, §3.8) gives
$$
2^n = \sum_{k=0}^{n}\binom nk,
$$
since $\binom nk$ counts the $k$-element subsets. The same partition argument used above, applied to $k$-subsets, gives Pascal's rule
$$
\binom{n}{k} = \binom{n-1}{k-1}+\binom{n-1}{k}
$$
— subsets containing $a$ versus not — and so the binomial theorem by induction. The theorem of this module is the binomial theorem evaluated at $x=y=1$.

## Why the split is legitimate

The inductive step divided the subsets of $S$ into those containing a fixed $a$ and those not, then claimed each group has $2^k$ members. Two conditions had to hold for the final addition, and both were checked.

**Disjoint.** No subset is in both groups, since a subset either contains $a$ or does not — the excluded middle of §1.3, and the reason the two counts do not overlap.

**Exhaustive.** Every subset is in one group, for the same reason.

Adding the sizes of overlapping groups double-counts; adding the sizes of groups with a gap undercounts. Neither check is automatic, and stating them is part of the proof.

**The bijection also needed verifying.** The map $T \mapsto T\cup\{a\}$ from Group 1 to Group 2 is injective because $T$ is recovered by removing $a$, and surjective (every possible output is actually hit, §3.6) because every subset containing $a$ arises this way. Only then does "each group has $2^k$ members" follow from the hypothesis, which was a statement about the subsets of a $k$-element set.

**Counting by pairing** — establishing a bijection with something already counted — is more powerful than counting one by one, and it is the only method that survives into the infinite case.

## The infinite case

> **Cantor's theorem.** For every set $S$, there is no surjection $S \to \mathcal{P}(S)$.

<Proof>
Let $f : S \to \mathcal{P}(S)$ and put $D = \{x \in S : x \notin f(x)\} \in \mathcal{P}(S)$.

If $D = f(d)$ for some $d \in S$, then $d \in D \iff d \notin f(d) = D$ — a contradiction. So $D \notin \operatorname{im}(f)$ and $f$ is not surjective (every possible output is actually hit, §3.6).
</Proof>

This is **not** an induction, and it cannot be turned into one: an arbitrary set has no *next*, so there is nothing to induct along. What it is instead is the move from §3.8 — build the one thing the list cannot contain, by disagreeing with every entry in turn. §2.1 used that same move to break something; here it builds something.

The finite theorem says $2^n > n$; the infinite version says it survives at every size of infinity. So there is no largest set and no largest infinity.

The power set of the counting numbers turns out to be the same size as the whole real line. Whether any size of infinity sits strictly between those two is a question the standard assumptions of mathematics can neither settle nor refute — one of the more startling discoveries of the last century, and a genuine limit rather than a gap in anyone's cleverness.

<WhereThisGoes level="l7">

Counting arguments are the everyday application of induction, and the two proofs in this module illustrate the choice this chapter keeps returning to.

**The induction verifies; the choice argument explains.** Building a subset by making one yes/no decision per element gives $2^n$ immediately, and it says *why* the base is $2$. The induction confirms the formula and does not.

The explanatory version also generalizes: give each element three options instead of two and the count is $3^n$, with no proof to redo. Rewriting the induction would be real work.

**In calculus, the binomial coefficients are what you will actually need.** $\binom nk$ counts $k$-element subsets of an $n$-set, and Pascal's identity
$$\binom nk + \binom{n}{k-1} = \binom{n+1}{k}$$
has exactly this module's proof: split the subsets of an $(n+1)$-set according to whether they contain a chosen element.

That identity is the inductive step of the binomial theorem, which in turn gives the expansion of $(1+x)^n$, and the derivative of $x^n$ worked out from the definition.

</WhereThisGoes>
