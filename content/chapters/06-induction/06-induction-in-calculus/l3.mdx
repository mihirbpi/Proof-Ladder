So far the claims came ready-made and you proved them. Real mathematics is not like that: usually you have to **find** the claim first, and only then prove it.

This module practices both halves. The version of it in the upper grades runs on calculus; the *method* is identical and does not need any.

## Job one: gather data

Start at $1$ and keep doubling.

| Doublings so far | Result |
|---|---|
| $0$ | $1$ |
| $1$ | $2$ |
| $2$ | $4$ |
| $3$ | $8$ |
| $4$ | $16$ |
| $5$ | $32$ |

The pattern is easy to say out loud: **the result is $2$ multiplied by itself as many times as you doubled.**

That was easy because there was only one thing happening. Usually two patterns are tangled together, and you have to pull them apart.

## A harder one, with two patterns at once

Start at $0$, and keep applying this rule: **double it, then add $1$.**

| Steps so far | Result |
|---|---|
| $0$ | $0$ |
| $1$ | $1$ |
| $2$ | $3$ |
| $3$ | $7$ |
| $4$ | $15$ |
| $5$ | $31$ |

Staring at $0, 1, 3, 7, 15, 31$ is hopeless if you try to see it all at once.

### Pulling the patterns apart

**Put the doubling list underneath it.**

| Steps | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|---|
| Our list | $0$ | $1$ | $3$ | $7$ | $15$ | $31$ |
| Doubling list | $1$ | $2$ | $4$ | $8$ | $16$ | $32$ |

Every single one is **exactly one less**.

So the guess is: *after any number of steps, the result is the doubling number for that step, minus $1$.*

Check it at $4$ steps: the doubling number is $16$, and $16 - 1 = 15$. ✓

## Job three: prove it

<Discussion>
  <div slot="know">Each result comes from the one before by doubling and adding $1$. And each doubling number is twice the one before it.</div>
  <div slot="want">The guess holds at every step, not just the six we checked.</div>
  <div slot="how">Dominoes. The first domino is the very first row. For the chain, assume the guess holds at some step and apply the rule once more.</div>
</Discussion>

<Proof>
**The first domino.** At $0$ steps the result is $0$. The doubling number is $1$, and $1 - 1 = 0$. ✓

**The chain.** Suppose that at some step the result is **one less than that step's doubling number**.

Apply the rule once more. Doubling our result doubles both parts: we get twice the doubling number, minus $2$.

Twice the doubling number is exactly the *next* doubling number.

Now add $1$, as the rule says. That leaves the next doubling number, minus $1$ — which is exactly what the guess predicts for the next step. ✓
</Proof>

<Warning title="Pull the patterns apart before combining them">
The list $0, 1, 3, 7, 15, 31$ is unreadable on its own and obvious once you set the doubling list beside it.

This is the general technique. When data resists, look for two simple patterns hiding inside it and find each one separately. Then put them back together.
</Warning>

<Aside>
The upper-grade version of this module does the same three jobs on a list that comes from calculus, where **three** patterns are tangled instead of two.

Gathering data, pulling the patterns apart, then proving the guess by dominoes — that is the whole method, and you have just done it. Only the list changes.
</Aside>
