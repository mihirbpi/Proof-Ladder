Module 1.7 gave you a fact: a claim and its contrapositive are always worth the same. This module turns that fact into a tool.

The tool is simple. If you are asked to prove *if A then B*, and the A you were handed is unpleasant to work with, **flip it around** and prove *if not B then not A* instead. Prove either one and you have proved both. This is called a **proof by contrapositive**.

## Two definitions first

- A counting number is **even** if it can be split into groups of $2$ with nothing left over.
- A counting number is **odd** if it is not even — there is always exactly one left over.

## The claim

> **Claim.** If a number multiplied by itself is odd, then the number is odd.

Check it. Take $3$: $3 \times 3 = 9$, which is odd, and $3$ is odd. ✓ Take $5$: $5 \times 5 = 25$, odd, and $5$ is odd. ✓

Now try to prove it directly. You start with *this number multiplied by itself is odd*, which means it leaves one left over when you group by two. What does that tell you about the number you started with? Nothing obvious. You are stuck at the first step — and being stuck at the first step is the signal.

## Plan the flip

<Discussion>
  <div slot="know">Nothing usable yet. Starting from "the number multiplied by itself is odd" gives us no handle on the number itself.</div>
  <div slot="want">To show the number is odd.</div>
  <div slot="how">Flip it around. The contrapositive is: *if the number is not odd, then the number multiplied by itself is not odd* — that is, **if the number is even, then multiplied by itself it is even.** Now what we are given is "the number is even", which tells us it is a pile of $2$s. That we can work with.</div>
</Discussion>

Do you see why the flip helped? "Even" is a *positive* description — it tells you what the number is made of. "Odd" only tells you what it isn't. Positive descriptions are easier to compute with, so if the odd one is in your *if* part, flip.

## The proof

<Proof>
We prove the contrapositive: if a number is even, then that number multiplied by itself is even.

Take any even counting number and follow it. Being even, it splits into groups of $2$ with nothing left over — say it is $2$ added to itself some number of times.

Now multiply your number by itself. You are taking your number, and making that many copies of it.

Each copy is $2$ added to itself some number of times. So the whole thing is still made only of $2$s, with nothing left over.

A number made only of groups of $2$ is even. So your number multiplied by itself is even.

We have proved the contrapositive, so the original claim — if a number multiplied by itself is odd, then the number is odd — is proved as well.
</Proof>

Notice what the proof did *not* do: it never picked a particular number. It said "take any even number and follow it", and every step worked no matter which one you took. That is the *for all* move from module 1.12, and it is how one argument covers infinitely many cases.

## The habit to build

Always **announce the switch**. The first line said "we prove the contrapositive," and the last line said what that means for the original claim. A reader who missed the announcement would think you had proved the wrong thing.

<Warning title="Flip the good way, not any way">
The contrapositive swaps the parts **and** says *not* to both. If you only swap, you get the converse — a different claim that might be false. If you only negate, you get the inverse — also different.

Getting this wrong means proving something true and then claiming something you never proved.
</Warning>

<Aside>
A rough rule for when to reach for the contrapositive: look at the *if* part. If it is a "not" statement — not odd, not equal, not a rectangle — the contrapositive will turn it into a plain statement, and plain statements are easier to use.
</Aside>
