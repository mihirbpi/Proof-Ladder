Look at the door.

*The door is open.*

Now the **opposite**:

*The door is not open.*

If the door is really open, then the first one is true. The **opposite** is not true.

If the door is closed, then the first one is not true. The **opposite** is true.

They can't both be true at the same time. One is true. The other is not.
