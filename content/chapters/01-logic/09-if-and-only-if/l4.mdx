The **if-and-only-if statement** $p \Leftrightarrow q$, read "$p$ if and only if $q$", is by definition
$$p \Leftrightarrow q \;\;\equiv\;\; (p \Rightarrow q) \wedge (q \Rightarrow p).$$

*Symbol by symbol: $\Leftrightarrow$ is "exactly when", $\Rightarrow$ is "forces", $\wedge$ is "and", $\equiv$ is "says the same as".*

It asserts that $p$ and $q$ stand or fall together. Its truth table follows from the definition:

$p \Leftrightarrow q$ is true exactly on the rows where $p$ and $q$ agree. Since the *and* has two halves, proving an if-and-only-if statement means writing **two proofs**. The named move is **check both boxes**.

## The theorem

*Two symbols appear below. $\in$ reads "is in", and $\mathbb{Z}$ is the shorthand for the whole collection of integers — so "$k \in \mathbb{Z}$" is just "$k$ is an integer". The proofs themselves are written in words.*

> **Theorem.** For every integer $n$: $n$ is even **if and only if** $n^2$ is even.

Definitions (and note these are themselves if-and-only-if statements): $n$ is **even** iff $n = 2k$ for some integer $k$; $n$ is **odd** iff $n = 2k+1$ for some integer $k$. Every integer is exactly one of the two.

<Discussion>
  <div slot="know">Both directions to prove. (backward) has hypothesis "$n$ even", which unfolds to $n = 2k$ — immediately usable. (forward) has hypothesis "$n^2$ even", which unfolds to $n^2 = 2k$ — and there is no way to get from that to a statement about $n$ without inverting a square.</div>
  <div slot="want">$n$ even $\Rightarrow$ $n^2$ even, and $n^2$ even $\Rightarrow$ $n$ even.</div>
  <div slot="how">Prove the easy direction directly. For the hard one, flip it around: the contrapositive of "$n^2$ even $\Rightarrow$ $n$ even" is "$n$ odd $\Rightarrow$ $n^2$ odd", whose hypothesis unfolds to $n = 2k+1$ — usable.</div>
</Discussion>

## Proof

<Proof>
**(forward) If $n$ is even then $n^2$ is even.**
Suppose $n$ is even, so $n = 2k$ for some integer $k$. Then $n^2 = 4k^2 = 2(2k^2)$, and $2k^2$ is an integer, so $n^2$ is even.

**(backward) If $n^2$ is even then $n$ is even.**
We prove the contrapositive: if $n$ is odd then $n^2$ is odd. Suppose $n$ is odd, so $n = 2k+1$ for some integer $k$. Then
$$n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1,$$
and $2k^2 + 2k$ is an integer, so $n^2$ is odd. By contraposition, $n^2$ even implies $n$ even.

Both directions hold, so $n$ is even $\Leftrightarrow$ $n^2$ is even.
</Proof>

Notice that the two halves needed different techniques. That is normal, and it is the reason an if-and-only-if statement cannot be proved by a single symmetrical argument.

<Warning title="Two halves, two labels">
Always label the directions — (forward) and (backward), or "forward" and "backward". Two things go wrong without labels: you prove the same direction twice without noticing, or you prove one and stop. Both errors are common and both are invisible in unlabelled prose.
</Warning>

## Definitions go both ways

Mathematical definitions are stated with "if" but always mean "if and only if":

> An integer $n$ is *even* if $n = 2k$ for some integer $k$.

Written out in symbols, that reads

$$n \text{ is even} \iff \exists k \in \mathbb{Z},\ n = 2k.$$

*Symbol by symbol: $\mathbb{Z}$ is the integers, $\in$ is "is in", $\exists$ is "there is some", $\Leftrightarrow$ is "exactly when".*

Take it one piece at a time: $\iff$ is *if and only if*, $\exists$ is *there exists* (§1.10 does this properly), and $k \in \mathbb{Z}$ is *$k$ is an integer*. So the whole line says: **$n$ is even exactly when you can find an integer $k$ with $n = 2k$.** That sentence and that formula say the same thing, and for now the sentence is the one to hold on to. Both directions are available to you. When you assume "$n$ is even" and write $n = 2k$, you are using one direction; when you finish a computation at $2(\text{something integer})$ and declare the result even, you are using the other. Most proofs in this course use both directions of some definition, usually within four lines of each other.

<Aside>
Other phrasings of the same thing, all of which you will meet: "$p$ is *necessary and sufficient* for $q$"; "$p$ *exactly when* $q$"; "$p$ iff $q$". And a warning about the last one: some authors write a chain $p \Leftrightarrow r \Leftrightarrow s \Leftrightarrow q$. This is legitimate only if every single link is genuinely reversible. Chains built with $\Rightarrow$ steps that were quietly written as $\Leftrightarrow$ are a rich source of false proofs — squaring both sides of an equation is the classic non-reversible step.
</Aside>

## This theorem matters later

The result just proved is not a toy. It is the lemma that makes the proof of the irrationality of $\sqrt{2}$ work (module 4.7): there, one shows $a^2$ is even, concludes $a$ is even, and that step is exactly the (backward) direction above — the one that needed the contrapositive.
