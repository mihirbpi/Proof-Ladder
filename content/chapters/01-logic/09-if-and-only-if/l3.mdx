An if–then claim runs one way only. *If a shape is a square, it is a rectangle* — and module 1.7 showed the reverse can fail badly, because plenty of rectangles are not squares.

But sometimes both directions really do hold. When they do, we say the two statements are true **if and only if** each other, and we call such a claim a **if-and-only-if statement**.

> "A if and only if B" means both of these at once:
> - if A then B,
> - if B then A.

Two claims glued together. So proving one takes two proofs, and the named move is **check both boxes**.

## Our claim

> **Claim.** A shape is a square **if and only if** it is a rectangle with four equal sides.

Everyone believes this. Almost nobody has checked both directions. Let's do it.

Recall the definitions you use when sorting shapes:

- A **rectangle** is a four-sided shape with four square corners.
- A **square** is a four-sided shape with four square corners and four equal sides.

<Discussion>
  <div slot="know">What "square" and "rectangle" each mean, from the definitions above.</div>
  <div slot="want">Box 1: every square is a rectangle with four equal sides. Box 2: every rectangle with four equal sides is a square.</div>
  <div slot="how">Both boxes are short here, because both come straight from unfolding the definitions. That is normal for a definition-based claim, and it is worth seeing once before the harder examples.</div>
</Discussion>

<Proof>
**Box 1: if a shape is a square, then it is a rectangle with four equal sides.**

Take any square. By the definition of square, it has four sides, four square corners, and four equal sides.

Having four sides and four square corners is exactly what makes a shape a rectangle. So it is a rectangle, and it has four equal sides. ✓

**Box 2: if a shape is a rectangle with four equal sides, then it is a square.**

Take any rectangle with four equal sides. Being a rectangle, it has four sides and four square corners. We were also told its four sides are equal.

Four sides, four square corners, four equal sides — that is exactly the definition of a square. ✓

Both boxes are checked, so the claim holds in both directions.
</Proof>

## A number one

Here is an if-and-only-if statement where the two halves need genuinely different work.

> **Claim.** A counting number is even **if and only if** its last digit is $0$, $2$, $4$, $6$, or $8$.

<Discussion>
  <div slot="know">Every counting number is some number of tens plus a last digit — $746$ is $74$ tens and $6$. And $10$ is even, so any number of tens is even.</div>
  <div slot="want">Both directions.</div>
  <div slot="how">The key is that the tens part is always even, so whether the whole number is even depends only on the last digit.</div>
</Discussion>

<Proof>
Split any counting number into its tens part and its last digit.

Since $10$ splits into $2$ groups of $5$, ten is even — and so is any number of tens, because you are adding even amounts together.

**Box 1: if the number is even, then the last digit is $0$, $2$, $4$, $6$, or $8$.**

Suppose the whole number is even. The tens part is even. Taking an even amount away from an even amount leaves an even amount, so the last digit is even. The even digits are $0$, $2$, $4$, $6$, $8$. ✓

**Box 2: if the last digit is $0$, $2$, $4$, $6$, or $8$, then the number is even.**

Suppose the last digit is one of those. Then the last digit is even, and the tens part is even, and adding two even amounts gives an even amount. So the whole number is even. ✓

Both boxes checked.
</Proof>

## Definitions usually go both ways

Here is something worth noticing. When we say

> a number is **even** if it splits into groups of $2$ with nothing left over,

we really mean *if and only if*. A number is even exactly when it splits that way — nothing else counts as even, and nothing that splits that way misses out.

Mathematicians write "if" in definitions out of long habit, but they always mean "if and only if." Once a definition is written down, you may use it in **both directions**, and you constantly will.

<Warning title="Half a proof is not a proof">
The commonest mistake with an if-and-only-if statement is proving one direction, feeling satisfied, and stopping.

If you have shown *every square is a rectangle*, you have not ruled out some rectangle sneaking in as a square. Label your two halves. Count them before you write $\square$.
</Warning>

<Aside>
The two directions often need different tools. In module 1.8 you proved *if a number times itself is odd then the number is odd* by flipping it around, because a direct attempt went nowhere. The other direction goes through directly with no trouble. Same if-and-only-if statement, two different techniques.
</Aside>
