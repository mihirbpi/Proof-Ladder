A single statement is rarely what a theorem is about. Theorems say things like "if $n$ is even *and* $n > 2$, then …" — compound statements built from simpler ones. This module fixes the meaning of the two basic joining words that do the building.

Throughout, $p$ and $q$ stand for statements.

## Conjunction — "and"

The **conjunction** of $p$ and $q$, written $p \wedge q$ and read "$p$ and $q$," is true exactly when both are true.

<TruthTable
  variables={["p", "q"]}
  expressions={["p ∧ q"]}
  rows={[
    { p: true,  q: true,  "p ∧ q": true  },
    { p: true,  q: false, "p ∧ q": false },
    { p: false, q: true,  "p ∧ q": false },
    { p: false, q: false, "p ∧ q": false }
  ]}
/>

One true row out of four. Conjunction is demanding.

Example: let $p$ be "$12$ is a multiple of $3$" (T) and $q$ be "$12$ is a multiple of $5$" (F). Then $p \wedge q$ is false. Half of a conjunction being true earns nothing.

## Disjunction — "or"

The **disjunction** of $p$ and $q$, written $p \vee q$ and read "$p$ or $q$," is true exactly when at least one is true.

<TruthTable
  variables={["p", "q"]}
  expressions={["p ∨ q"]}
  rows={[
    { p: true,  q: true,  "p ∨ q": true  },
    { p: true,  q: false, "p ∨ q": true  },
    { p: false, q: true,  "p ∨ q": true  },
    { p: false, q: false, "p ∨ q": false }
  ]}
/>

Three true rows. Disjunction is generous — and note the very first row: when *both* are true, $p \vee q$ is still true.

<Warning title="Inclusive or">
English often uses *or* exclusively: "you may have soup or salad" means one, not both. Mathematics never does. $\vee$ is the **inclusive or**: at least one, both permitted. If a mathematician wants exclusive or, they say so explicitly — "exactly one of $p$, $q$ holds."
</Warning>

## Two special columns

Some compound statements have a truth-table column that never changes.

*A reminder of the symbols in play: $\neg$ reads "not".*

<TruthTable
  variables={["p"]}
  expressions={["¬p", "p ∧ ¬p", "p ∨ ¬p"]}
  rows={[
    { p: true,  "¬p": false, "p ∧ ¬p": false, "p ∨ ¬p": true },
    { p: false, "¬p": true,  "p ∧ ¬p": false, "p ∨ ¬p": true }
  ]}
/>

- $p \wedge \neg p$ is false in every row. A statement false under every assignment of truth values is a **contradiction**.
- $p \vee \neg p$ is true in every row. A statement true under every assignment is a **tautology**.

Neither depends on what $p$ actually says. "$12$ is prime and $12$ is not prime" is false; so is "the moon is cheese and the moon is not cheese." The *shape* decides.

<Aside>
$p \vee \neg p$ has a name — the *law of the excluded middle* — and it is doing real work every time you say "either it is, or it isn't." Module 2.5 turns contradictions into a proof technique: assume the negation of your goal, derive a contradiction, and conclude the goal.
</Aside>

## Reading compound statements carefully

Consider: "$n$ is a multiple of $2$ **and** $n$ is a multiple of $3$."

- $n = 6$: T $\wedge$ T = T.
- $n = 8$: T $\wedge$ F = F.
- $n = 9$: F $\wedge$ T = F.
- $n = 7$: F $\wedge$ F = F.

Only $n$ divisible by both survives — the multiples of $6$. Compare with *or*, which would keep $6, 8, 9$ and drop only $7$.

That comparison is worth holding onto. In Chapter 2 you will meet $\cap$ (intersection) and $\cup$ (union) and discover that they are $\wedge$ and $\vee$ wearing different clothes: an element is in $S \cap T$ when it is in $S$ **and** in $T$, and in $S \cup T$ when it is in $S$ **or** in $T$. Every fact you learn about the joining words here will come back as a fact about sets.

## Where you have already been using both

Every solution set you have written in algebra was one of these two words in disguise.

**A pair of conditions on one variable.** Solving $-3 < x$ and $x < 5$ at once gives the numbers between $-3$ and $5$. That is an *and*: a number must pass **both** tests to make the cut, and failing either one is enough to be excluded.

**A product that is zero.** From $(x-2)(x+3) = 0$ you conclude $x = 2$ **or** $x = -3$. That is an *or*, and it comes from a genuine fact about numbers: a product is zero only when one of its factors is. Notice that the *or* is inclusive here too — nothing would break if both factors were zero, and for the equation $(x-2)^2 = 0$ that is exactly what happens.

**A system of equations.** Two equations solved simultaneously is an *and*: the answer must satisfy the first **and** the second. The picture is the crossing point of two lines, and a crossing point is exactly a point lying on both.

<Warning title="An *and* shrinks; an *or* grows">
Adding a condition with *and* can only make a solution set smaller or leave it alone, because every new test is another chance to be excluded.

Adding one with *or* can only make it bigger or leave it alone, because a new way to qualify never disqualifies anything.

Checking your answer against that rule catches a surprising number of algebra slips. If you added a requirement and your set of solutions grew, something went wrong.
</Warning>
