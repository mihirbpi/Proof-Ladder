## Definition

$f : S \to T$ is **injective** (or **one-to-one**) when
$$
\forall s_1, s_2 \in S,\quad s_1 \neq s_2 \;\Rightarrow\; f(s_1) \neq f(s_2).
$$

*Symbol by symbol: $\in$ is "is in", $\forall$ is "for every", $\Rightarrow$ is "forces". So the line reads: different inputs always give different outputs.*

Equivalently, by contraposition (module 1.7),
$$
\forall s_1, s_2 \in S,\quad f(s_1) = f(s_2) \;\Rightarrow\; s_1 = s_2. \tag{I}
$$

*Symbol by symbol: $\in$ is "is in", $\forall$ is "for every", $\Rightarrow$ is "forces". So the line reads: if two inputs give the same output, they were the same input all along.*

**Use form (I).** The two are logically identical, but the first has a negation as its hypothesis and negations give you nothing to substitute; the second hands you an equation. This is module 1.8's decision rule applied to a definition, and it is the reason essentially every injectivity proof in mathematics opens with "suppose $f(s_1) = f(s_2)$."

Said with pre-images (module 3.3): $f$ is injective iff $|f^{-1}(\{t\})| \leq 1$ for every $t \in T$.

## Proving injectivity

The template is fixed:

> Let $s_1, s_2 \in S$ with $f(s_1) = f(s_2)$. … Therefore $s_1 = s_2$. So $f$ is injective.

> **Proposition.** $f : \mathbb{Z} \to \mathbb{Z}$, $f(n) = 2n$, is injective.

<Discussion>
  <div slot="know">$2a = 2b$ for some integers $a, b$. Available: doubling is strictly increasing — bigger input, bigger output.</div>
  <div slot="want">$a = b$.</div>
  <div slot="how">Divide both sides by $2$. Or, without dividing: use the fact that a strictly increasing rule can never send two different inputs to the same place.</div>
</Discussion>

<Proof>
Let $a, b \in \mathbb{Z}$ with $2a = 2b$.

Suppose $a \neq b$. Then one of them is smaller; say $a < b$, since the other case is the same argument with the two letters swapped. Doubling preserves order, so $a < b$ gives $2a < 2b$ — contradicting $2a = 2b$.

So $a = b$, and $f$ is injective.
</Proof>

That argument proves something more general and worth stating: **every strictly increasing rule is injective.** If $a < b$ always forces $f(a) < f(b)$ (or always forces $f(a) > f(b)$), then distinct inputs cannot share an output. This is by far the commonest way injectivity gets proved in practice.

## Disproving injectivity

One collision is enough — module 1.11's *one bad apple*, since injectivity is a universal claim.

**$f(x) = x^2$ on $\mathbb{R}$:** $f(3) = f(-3) = 9$ with $3 \neq -3$. Not injective.

**$m : \mathbb{Z}\times\mathbb{Z} \to \mathbb{Z}$, $m(a,b) = ab$:** $m(6,4) = 24 = m(2,12)$ with $(6,4) \neq (2,12)$. Not injective.

**Floor:** $\lfloor 3.1 \rfloor = \lfloor 3.9 \rfloor = 3$. Not injective.

Notice how cheap disproof is compared to proof. That asymmetry is module 1.12's table, and it is why you should always spend thirty seconds hunting for a collision before attempting a proof.

<Warning title="Injectivity depends on the domain">
$f(x) = x^2$ is not injective on $\mathbb{R}$. Restricted to $[0,\infty)$ it *is* injective: if $a, b \geq 0$ and $a^2 = b^2$ then $a^2 - b^2 = (a-b)(a+b) = 0$, and since $a + b > 0$ unless $a = b = 0$, we get $a = b$ in every case.

Changing the domain changes the function (module 3.1), so it can change the answer. This is exactly why $\sqrt{\phantom{x}}$ is defined as the inverse of squaring *on the non-negatives*.
</Warning>

## Injectivity and the pre-image

Injective functions are the ones whose images behave. Module 3.4 noted that $f(A \cap B) \subseteq f(A) \cap f(B)$ can be strict; equality for all $A, B$ holds exactly when $f$ is injective. Likewise $A = f^{-1}(f(A))$ for all $A \subseteq S$ exactly when $f$ is injective.

So "injective" is not merely a curiosity about arrows. It is the condition under which the forward direction stops losing information.

<Aside>
The horizontal line test is (I) drawn on axes: a horizontal line meeting the graph twice exhibits two inputs with one output. Contrast the vertical line test, which asks whether the graph is a function at all (module 3.1). Two lines, two questions, frequently confused.
</Aside>

## What is still missing

Injectivity says every $t \in T$ has *at most* one pre-image. It says nothing about whether every $t$ has *at least* one — some targets may be unhit. Doubling on $\mathbb{Z}$ is injective, yet no input produces $3$.

That other half is module 3.6, and having both at once is module 3.8.
