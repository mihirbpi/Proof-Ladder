The definition in module 3.1 mentioned no formulas and no numbers. This module is a collection of functions that exercise that generality, because the belief that "function = formula" quietly breaks everything that follows.

*A reminder from module 3.1: $f(x)$ is read "$f$ of $x$" and denotes the one output the rule $f$ assigns to the input $x$.*

## The floor function

$$
\lfloor \cdot \rfloor : \mathbb{R} \to \mathbb{Z}, \qquad
\lfloor x \rfloor = \text{the largest integer } n \text{ with } n \leq x.
$$

*Symbol by symbol: $\mathbb{Z}$ is the integers, $\mathbb{R}$ is the real numbers, the arrow says what goes in and what comes out. So the line reads: *Read the first part as "floor takes a real number and returns an integer"; the arrow says what goes in and what comes out.*

$$
\lfloor 3.7 \rfloor = 3, \quad \lfloor 5 \rfloor = 5, \quad \lfloor -2.3 \rfloor = -3, \quad \lfloor -5 \rfloor = -5.
$$

The negative cases are where people slip. $\lfloor -2.3\rfloor$ is not $-2$: floor rounds *down the number line*, so it is $-3$. Truncation toward zero is a different function, and confusing the two produces off-by-one errors in every subject that uses either.

Two facts that make floor usable in proofs:
$$
\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1,
\qquad
\lfloor n + x \rfloor = n + \lfloor x \rfloor \text{ for } n \in \mathbb{Z}.
$$

*Symbol by symbol: $\mathbb{Z}$ is the integers, $\in$ is "is in". So the line reads: the floor of $x$ is no bigger than $x$ and less than one more than $x$; and shifting $x$ by a whole number shifts its floor by that same whole number.*

Floor is total and single-valued on all of $\mathbb{R}$, so it is a function $\mathbb{R} \to \mathbb{Z}$ — but it is given by a *characterization*, not by an arithmetic expression.

## Euler's totient

For $n \geq 1$, **Euler's totient** $\operatorname{tot}(n)$ counts the integers in $\{1, \ldots, n\}$ sharing no common factor with $n$ other than $1$:
$$
\operatorname{tot}(n) = \big|\{\, k \in \mathbb{Z} \mid 1 \leq k \leq n,\ \gcd(k,n) = 1 \,\}\big|.
$$

*Symbol by symbol: $\mathbb{Z}$ is the integers, $\in$ is "is in", the bar $\mid$ is "such that". So the line reads: the totient of $n$ counts the whole numbers from $1$ to $n$ that share no factor with $n$.*

Computing the first twelve by hand:

| $n$ | coprime $k \leq n$ | $\operatorname{tot}(n)$ |
|---|---|---|
| $1$ | $1$ | $1$ |
| $2$ | $1$ | $1$ |
| $3$ | $1,2$ | $2$ |
| $4$ | $1,3$ | $2$ |
| $5$ | $1,2,3,4$ | $4$ |
| $6$ | $1,5$ | $2$ |
| $7$ | $1,\ldots,6$ | $6$ |
| $8$ | $1,3,5,7$ | $4$ |
| $9$ | $1,2,4,5,7,8$ | $6$ |
| $10$ | $1,3,7,9$ | $4$ |
| $11$ | $1,\ldots,10$ | $10$ |
| $12$ | $1,5,7,11$ | $4$ |

A pattern jumps out of rows $2, 3, 5, 7, 11$:
$$
\operatorname{tot}(p) = p - 1 \quad\text{for } p \text{ prime.}
$$
And it is easy to see why: if $p$ is prime, its only divisors are $1$ and $p$, so every one of $1, \ldots, p-1$ is coprime to it, and $p$ itself is not.

### Why it is a function at all

$p$ is a function $\mathbb{Z}_{\geq 1} \to \mathbb{Z}_{\geq 1}$ defined by a counting procedure. No closed-form expression is used, and none is needed.

## Multiplication as a function on a product

$$
m : \mathbb{Z} \times \mathbb{Z} \to \mathbb{Z}, \qquad m(a,b) = ab.
$$

*Symbol by symbol: $\mathbb{Z}$ is the integers, the arrow says what goes in and what comes out, $\times$ pairs things up. So the line reads: *Read it as "$m$ takes a pair of integers and returns an integer" — and what it returns is their product.*

The domain is the product set of module 2.9. Viewing a two-input operation this way is not a formality: it lets the whole vocabulary of this chapter apply to them. For instance $m$ is not injective ($m(6,4) = m(2,12) = 24$) but is surjective ($m(n,1) = n$), facts that only make sense once $m$ is regarded as a function.

## Domain restrictions are consequences, not conventions

$$
r(x) = \frac{1}{x}, \qquad s(x) = \sqrt{x}.
$$

Neither is a function on $\mathbb{R}$. For $r$, totality fails at $0$ — there is no real number $1/0$, so no value can be assigned. For $s$, totality fails on $(-\infty, 0)$, because $y^2 \geq 0$ for every real $y$, so no $y$ satisfies $y^2 = x$ when $x < 0$.

In both cases the correct move is to declare the domain honestly:
$$
r : \mathbb{R}\setminus\{0\} \to \mathbb{R}, \qquad s : \mathbb{R}_{\geq 0} \to \mathbb{R}.
$$

*Symbol by symbol: $\mathbb{R}$ is the real numbers. So the line reads: $r$ accepts any number except zero and returns a number; $s$ accepts any number that is zero or bigger.*

The excluded points were never arbitrary; they are exactly where the assignment fails to exist.

<Warning title="Well-definedness must be checked, not assumed">
A rule on a domain whose elements have multiple names must give the same answer for every name.

**Not a function:** $f : \mathbb{Q} \to \mathbb{Z}$, $f(p/q) = p + q$. Since $\tfrac12 = \tfrac24$ but $1+2 \neq 2+4$, the same input receives two outputs.

**A function:** $g : \mathbb{Q} \to \mathbb{Q}$, $g(p/q) = p^2/q^2$. Here if $p_1/q_1 = p_2/q_2$ then $p_1q_2 = p_2q_1$, so $p_1^2q_2^2 = p_2^2q_1^2$, so $p_1^2/q_1^2 = p_2^2/q_2^2$ — the check is a short proof, and it is required.

Every definition on fractions, or on numbers grouped by the remainder they leave, carries this obligation.
</Warning>

<Aside>
$p$ is easy to compute if you know how $n$ factors and, as far as anyone knows, hard otherwise. That asymmetry is the basis of RSA encryption: publishing $n = pq$ reveals almost nothing about $\operatorname{tot}(n) = (p-1)(q-1)$ unless you can factor $n$, and factoring large integers is believed to be computationally infeasible.
</Aside>
