## Definition

$f : S \to T$ is **surjective** (or **onto**) when
$$
\forall t \in T,\ \exists s \in S,\ f(s) = t,
$$

*Symbol by symbol: $\in$ is "is in", $\forall$ is "for every", $\exists$ is "there is some". So the line reads: for every target in $T$ there is at least one input that hits it.*

Two other ways to say the same thing: the image of $f$ is the whole of $T$; or, at least one input lands on each target.

Compare with injectivity, which said *at most* one pre-image. Injectivity and surjectivity are the two halves of "exactly one", and having both is module 3.8.

## The shape of the proof

The definition is a *for every … there is …* claim, so module 1.12 fixes the proof shape: take any target, then **produce a witness** — an input that lands on it. The witness is almost always built out of the target, and finding the formula for it is where the work lies.

> Take any target $t$. Set $s = \ldots$ [built from $t$]. Then $s$ is in $S$, and $f(s) = t$. So $f$ is surjective.

Note the small thing to check that is easy to skip: you must check the witness actually lies in $S$.

> **Proposition.** Doubling, taken as a function from the integers **to the even integers**, is surjective.

<Discussion>
  <div slot="know">$t$ is even. Available: an even number is by definition $2$ times an integer, so $t/2$ is an integer.</div>
  <div slot="want">Some integer $n$ with $2n = t$.</div>
  <div slot="how">The witness is $n = t/2$. The hypothesis that $t$ is even is exactly what makes $t/2$ an integer, so it is doing real work — this is where the choice of codomain enters.</div>
</Discussion>

<Proof>
Take any $t \in E$. Since $t$ is even, $t = 2k$ for some integer $k$, so the number $n = t/2 = k$ is an integer — so $n \in \mathbb{Z}$.

Then $g(n) = 2 \cdot \frac{t}{2} = t$.

Nothing was assumed about $t$ of $E$, every element of the codomain is attained, so $g$ is surjective.
</Proof>

## The codomain decides

> **The same rule with a different codomain.** Doubling, taken as a function from the integers to *all* the integers, is **not** surjective.

<Proof>
Take $t = 3 \in \mathbb{Z}$. For every $n \in \mathbb{Z}$ the value $2n$ is even, and $3$ is odd, so no $n$ satisfies $f(n) = 3$. So $\operatorname{Im}(f) \neq \mathbb{Z}$.
</Proof>

$f$ and $g$ have the same rule and the same domain, and differ only in the declared codomain — and one is surjective while the other is not. Module 3.1 insisted that domain and codomain are part of the function; this is the sharpest illustration of why.

<Warning title="Injectivity and surjectivity are not symmetric in this respect">
Injectivity depends only on the rule and the domain: enlarging the codomain cannot create a collision. Surjectivity depends on the codomain essentially.

Consequently "is $f$ injective?" is a well-posed question once you know the rule and domain, while "is $f$ surjective?" is not well-posed until the codomain is stated.
</Warning>

## Disproving surjectivity

Denying *every target is hit* gives, by module 1.11:
$$
\exists t \in T,\ \forall s \in S,\ f(s) \neq t.
$$

*Symbol by symbol: $\in$ is "is in", $\forall$ is "for every", $\exists$ is "there is some". So the line reads: there is some target in $T$ that no input hits at all.*

So you exhibit **one** unhit target — and then prove *nothing* hits it, which is a universal claim requiring an argument, not a search. That second half is what people forget.

In the doubling example above, the unhit target was $3$ and the universal argument was "$2n$ is even for every $n$."

## More examples

| Function | Surjective? | Why |
|---|---|---|
| $\lfloor\cdot\rfloor : \mathbb{R}\to\mathbb{Z}$ | Yes | given $n \in \mathbb{Z}$, take $x = n$ |
| $m : \mathbb{Z}\times\mathbb{Z}\to\mathbb{Z}$, $m(a,b)=ab$ | Yes | given $n$, take $(n,1)$ |
| $f : \mathbb{R}\to\mathbb{R}$, $f(x)=x^2$ | No | $-1$ is unhit, since $x^2 \geq 0$ |
| $f : \mathbb{R}\to[0,\infty)$, $f(x)=x^2$ | Yes | given $t \geq 0$, take $x = \sqrt t$ |
| $r : \mathbb{R}\setminus\{0\} \to \mathbb{R}$, $r(x)=1/x$ | No | $0$ is unhit |
| $r : \mathbb{R}\setminus\{0\} \to \mathbb{R}\setminus\{0\}$ | Yes | given $t \neq 0$, take $x = 1/t$ |

Three of these pairs are the same rule twice, with the codomain adjusted. That is the module in one table.

<Aside>
Any function becomes surjective if you replace its codomain by its image: $f : S \to \operatorname{Im}(f)$ is surjective by construction. So surjectivity measures whether the declared codomain was honest, and the standard factorisation $S \to \operatorname{Im}(f) \to T$ — onto the image, then into the codomain — writes any function as a surjection followed by an injection.
</Aside>
