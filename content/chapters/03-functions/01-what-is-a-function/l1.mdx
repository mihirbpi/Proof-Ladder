At school, every child has a cubby. That is a **machine**.

You put a child in. Out comes a cubby. Every time.

Sam goes to Sam's cubby. Pip goes to Pip's cubby. It always works.

Now, how could you break it?

**Broken way one.** A new child arrives. No cubby for them! Uh oh. A machine has to work for everybody.

**Broken way two.** Sam has *two* cubbies. Where do Sam's boots go? Nobody knows. A machine has to give one answer, not two.

Now here is a tricky one. Sam and Pip **share** one cubby.

Is that broken? No! Every child still has exactly one cubby. It is crowded, but the machine still works.
