A **function** $f : S \to T$ assigns to each $s \in S$ exactly one $f(s) \in T$. Formally, three conditions:

- **Totality.** $\forall s \in S,\ \exists t \in T,\ f(s) = t$.
- **Well-definedness.** $f(s) = t_1 \wedge f(s) = t_2 \Rightarrow t_1 = t_2$.
- **Codomain.** All values lie in $T$.

Together the first two are $\forall s \in S,\ \exists!\, t \in T,\ f(s) = t$ — §1.10's unique-existence quantifier, and the reason that module preceded this one.

Note what is *not* required. Nothing constrains the codomain side: distinct inputs may share an output (§3.5 studies its absence), and elements of $T$ may be unhit (§3.6). Beginners routinely import symmetry that is not there.

## The graph definition

The description above uses "assigns", which is no more defined than "function". The set-theoretic definition removes the circularity, using §2.9:

> A **function** from $S$ to $T$ is a triple $(S, T, G)$ where $G \subseteq S \times T$ satisfies
> $$\forall s \in S,\ \exists!\, t \in T,\ (s,t) \in G.$$
> One writes $f(s)$ for that unique $t$, and $G$ is the **graph** of $f$.

So a function *is* its graph, together with its domain and codomain. Three consequences worth stating:

1. **Functions are equal when their graphs and their domains and codomains are equal.** Hence $f = g$ iff they agree pointwise and have the same domain and codomain — extensionality one level up from §2.6.
2. **The codomain is data, not derivable.** $G$ determines the image but not $T$, which is why $T$ must be carried in the triple. Authors who define a function as just $G$ cannot state surjectivity, and this is a real defect.
3. **The vertical line test is this definition drawn on axes.** Not a separate criterion.

## Domain and codomain are constitutive

$$
f : \mathbb{R} \to \mathbb{R},\ f(x) = e^x
\qquad\text{and}\qquad
g : \mathbb{R} \to \mathbb{R}_{>0},\ g(x) = e^x
$$
are different functions with the same graph. $g$ is surjective and $f$ is not (§3.6); $g$ is invertible and $f$ is not (§3.9). Same rule, genuinely different mathematical objects.

The habit to acquire: never write down a rule without writing down its domain and codomain. Most of the confusion students report about injectivity and surjectivity dissolves once this is automatic.

<Warning title="Well-definedness is a proof obligation, not a formality">
When elements of the domain admit multiple names, a rule must be checked to give the same answer for all of them.

$f : \mathbb{Q} \to \mathbb{Z}$, $f(p/q) = p + q$ is **not** a function: $\tfrac12 = \tfrac24$ but $1+2 \neq 2+4$.

Grouping the integers by the remainder they leave on division by $n$, the rule $[a] \mapsto [a^2]$ **is** a function — but proving it requires showing that if $a$ and $b$ leave the same remainder then so do $a^2$ and $b^2$. (Written $a \equiv b \pmod n$ in later courses, and read *"congruent modulo $n$"*.) That is a genuine argument, not an observation.

Every construction on a quotient carries this obligation. It is the single most commonly skipped step in first algebra courses.
</Warning>

## Functions on product sets

A function of two variables is a function whose domain is a product:
$$
m : \mathbb{Z} \times \mathbb{Z} \to \mathbb{Z}, \qquad m(a,b) = ab.
$$
The notation $m(a,b)$ abbreviates $m\big((a,b)\big)$; the argument is a single element of $\mathbb{Z} \times \mathbb{Z}$. This viewpoint makes §3.5 and §3.6 apply verbatim to multi-variable functions — for instance $m$ is not injective, since $m(6,4) = m(2,12) = 24$, but it is surjective, since $m(n,1) = n$.

<Aside>
There is a second viewpoint, **currying**: a function $S \times T \to R$ corresponds bijectively to a function $S \to (T \to R)$, i.e. to a function returning a function. The correspondence is a bijection between $R^{S \times T}$ and $(R^T)^S$, which is the set-theoretic content of the exponent law $r^{st} = (r^t)^s$. It is the default in functional programming and in category theory, where it becomes the definition of a cartesian closed category.
</Aside>

## Partial functions, and why they are a different thing

$x \mapsto 1/x$ is not a function $\mathbb{R} \to \mathbb{R}$; totality fails at $0$. Two standard responses:

- **Restrict the domain.** $f : \mathbb{R}\setminus\{0\} \to \mathbb{R}$ is a genuine function. This is what mathematics does.
- **Allow partiality.** A *partial function* from $S$ to $T$ is a function defined on some subset of $S$. This is what computability theory does, because the halting problem makes partiality unavoidable: the function "output of program $p$ on input $n$" is genuinely undefined when the program does not halt, and there is no way to shrink the domain effectively.

Ordinary mathematics takes the first road, and "the domain of $1/x$" means the largest set on which the formula makes sense.

<WhereThisGoes level="l7">

Calculus is a course about functions, and almost every difficulty in it is a domain question in disguise.

**Totality is why domains must be stated.** $f(x) = 1/x$ is not a function on $\mathbb{R}$, and neither is $\tan x$, and neither is $\ln x$. Every one of the standard examples in a first calculus course arrives with a restriction, and the restriction is not a footnote — without it there is no function to differentiate.

The consequences are immediate and practical. The Mean Value Theorem requires $f$ to be defined on all of $[a,b]$; applying it to $1/x$ across $0$ produces nonsense, and the failure is a failure of totality. The Fundamental Theorem of Calculus requires continuity on the interval of integration, which is why $\int_{-1}^{1} \frac{1}{x^2}\,dx$ cannot be computed by antidifferentiating and evaluating.

**Single-valuedness is why inverse trigonometric functions have restricted ranges.** $\sin^{-1}$ must return one angle, so its domain is restricted before inverting, and that is why solving $\sin\theta = \frac12$ over all angles requires adding solutions back by hand.

</WhereThisGoes>
