## The question

Given $f : S \to T$, when is there a function $f^{-1} : T \to S$ that undoes it — that is, with
$$
f^{-1}\big(f(s)\big) = s \ \text{ for all } s \in S,
\qquad
f\big(f^{-1}(t)\big) = t \ \text{ for all } t \in T\,?
$$

*Symbol by symbol: $\in$ is "is in". So the line reads: does going forward and then back return you to where you started — and does going back and then forward?.*

*A reminder of the symbols in play: $\circ$ reads "after".*

Equivalently, $f^{-1} \circ f = \mathrm{id}_S$ and $f \circ f^{-1} = \mathrm{id}_T$.

## The answer, and why it is exactly right

To define $f^{-1}(t)$, we want to say: "the element $s$ with $f(s) = t$." That phrase carries two hidden jobs, and they are exactly the two properties of the last two modules.

**Such an $s$ must exist**, or $f^{-1}(t)$ has no value and totality fails. Existence for every $t \in T$ is *surjectivity*.

**Such an $s$ must be unique**, or $f^{-1}(t)$ has two values and well-definedness fails. Uniqueness is *injectivity*.

> **Theorem.** $f : S \to T$ has an inverse function if and only if $f$ is a bijection.

<Discussion>
  <div slot="know">Bijectivity is $\forall t \in T,\ \exists!\, s \in S,\ f(s) = t$ — *every target is hit by exactly one input* — module 3.8's one-element condition, and note it is literally the unique-existence quantifier of module 1.10.</div>
  <div slot="want">Both directions.</div>
  <div slot="how">(forward) Define $f^{-1}(t)$ to be the unique pre-image; surjectivity settles the first and injectivity settles the second. (backward) From a two-sided inverse, read off injectivity and surjectivity directly.</div>
</Discussion>

<Proof>
**(forward)** Suppose $f$ is a bijection. Let $t \in T$. Since $f$ is surjective, the set $f^{-1}(\{t\})$ is nonempty; since $f$ is injective, it has at most one element. So it has exactly one element, and we may define $f^{-1}(t)$ to be it. This is total (surjectivity) and single-valued (injectivity), so $f^{-1} : T \to S$ is a function.

By construction $f(f^{-1}(t)) = t$ for all $t \in T$. And for $s \in S$, the element $f^{-1}(f(s))$ is the unique pre-image of $f(s)$, which is $s$. So $f^{-1}\circ f = \mathrm{id}_S$ and $f \circ f^{-1} = \mathrm{id}_T$.

**(backward)** Suppose $g : T \to S$ satisfies $g \circ f = \mathrm{id}_S$ and $f \circ g = \mathrm{id}_T$.

*Injective:* if $f(s_1) = f(s_2)$, apply $g$ to get $s_1 = g(f(s_1)) = g(f(s_2)) = s_2$.

*Surjective:* given $t \in T$, the element $g(t) \in S$ satisfies $f(g(t)) = t$.

So $f$ is a bijection.
</Proof>

Note how cleanly the two halves of "exactly one" line up with the two halves of the definition of a function. That is the payoff of module 3.1 having separated totality from well-definedness.

## The inverse is a bijection

> **Proposition.** If $f$ is a bijection then so is $f^{-1}$, and $(f^{-1})^{-1} = f$.

<Proof>
$f$ itself is a two-sided inverse for $f^{-1}$, since $f \circ f^{-1} = \mathrm{id}_T$ and $f^{-1}\circ f = \mathrm{id}_S$. By the theorem's (backward) direction applied to $f^{-1}$, it is a bijection, and its inverse is $f$.
</Proof>

Inverses are also unique: if $g$ and $h$ both invert $f$, then $g = g \circ \mathrm{id}_T = g\circ(f\circ h) = (g\circ f)\circ h = \mathrm{id}_S \circ h = h$, using associativity from module 3.7. So "*the* inverse" is justified.

## Worked examples

**Doubling, $g : \mathbb{Z}\to E$, $g(n) = 2n$** is a bijection (module 3.8), so its inverse is halving, $g^{-1} : E \to \mathbb{Z}$. The identities "halve then double" and "double then halve" both return the input, and those are exactly the two composition conditions — not separate facts to memorize.

Note that doubling as a rule $\mathbb{Z}\to\mathbb{Z}$ is **not** invertible, since it is not surjective. This is why halving has domain $E$ rather than $\mathbb{Z}$: the domain of an inverse is the codomain of a bijection.

**$r : \mathbb{R}\setminus\{0\} \to \mathbb{R}\setminus\{0\}$, $r(x) = 1/x$.** A bijection, and it is its own inverse: $r(r(x)) = 1/(1/x) = x$. Functions equal to their own inverse are worth noticing; negation and complementation are others.

**Squaring.** The rule sending $x$ to $x^2$ on $\mathbb{R}$ is neither injective nor surjective, so no inverse. Restricted to $[0,\infty)\to[0,\infty)$ it becomes a bijection, and its inverse is $\sqrt{\phantom{x}}$. The familiar rule that $\sqrt{x^2} = |x|$ rather than $x$ is exactly the residue of that restriction.

<Warning title="Two objects, one notation">
$$f^{-1}(U) \text{ for } U \subseteq T \quad\text{(pre-image; always exists, module 3.3)}$$

*Symbol by symbol: $\subseteq$ is "sits inside". So the line reads: the traced-back set is defined for any **collection** of targets, and it always exists.*

$$f^{-1}(t) \text{ for } t \in T \quad\text{(inverse function; exists iff } f \text{ is a bijection)}$$

*Symbol by symbol: $\in$ is "is in". So the line reads: the inverse function is defined on a **single** target, and only exists when $f$ is a bijection.*

*Same notation, two different jobs: handed a whole collection it traces back and always works; handed a single element it needs $f$ to be a perfect pairing first.*

For $f(x) = x^2$ on $\mathbb{R}$: $f^{-1}(\{9\}) = \{3,-3\}$ is a perfectly good set; $f^{-1}(9)$ is meaningless.

When both exist they agree in the obvious way: $f^{-1}(\{t\}) = \{f^{-1}(t)\}$. The clash is universal and permanent; read the argument to tell them apart.
</Warning>

<Aside>
Restricting a domain to force invertibility is a move you will make again and again. Squaring is the first case; later, when you meet functions that repeat the same values over and over, each will have to be cut down to one stretch on which it is injective before it can be undone at all. Different choices of stretch give genuinely different inverse functions, and choosing one is part of the definition rather than a detail.
</Aside>
