For $f : S \to T$ and $g : T \to R$, the **composition** $g \circ f : S \to R$ is
$$
(g\circ f)(s) = g(f(s)),
$$

*Symbol by symbol: $\circ$ is "after".*

defined exactly when the codomain of $f$ equals the domain of $g$. That $g \circ f$ is a function requires no verification: totality, single-valuedness, and codomain membership are inherited.

Read $g \circ f$ as "$g$ after $f$". The convention matches the nesting in $g(f(s))$ and is universal in mathematics; the opposite convention $f;g$ appears in computer science and in some category-theory texts, and clashes between them are a standard source of sign and order errors when moving between subjects.

## Algebraic structure

**Associativity.** For $f : S\to T$, $g : T \to R$, $h : R \to Q$,
$$
\big(h \circ (g\circ f)\big)(s) = h(g(f(s))) = \big((h\circ g)\circ f\big)(s),
$$

*Symbol by symbol: $\circ$ is "after".*

so parentheses may be dropped.

**Identities.** $\mathrm{id}_S : S \to S$, $\mathrm{id}_S(s) = s$, satisfies $f \circ \mathrm{id}_S = f = \mathrm{id}_T \circ f$.

**Non-commutativity.** $f(x)=x+1$, $g(x)=2x$ on $\mathbb{R}$ give $g\circ f = 2x+2$ and $f \circ g = 2x+1$. Often only one composite is even defined.

These three facts are exactly the axioms of a **category**: objects (sets), arrows (functions), an associative composition, and identities. Everything proved below uses only those three ingredients, and that is why it recurs verbatim for groups, spaces, and modules.

## Preservation theorems

> **Proposition.** If $f, g$ are injective, so is $g \circ f$. If $f, g$ are surjective, so is $g\circ f$.

<Discussion>
  <div slot="know">Injectivity in the form $f(a)=f(b) \Rightarrow a=b$; surjectivity in the form $\forall t\,\exists s$.</div>
  <div slot="want">The same properties for the composite.</div>
  <div slot="how">The injectivity argument peels the hypotheses from the outside in — $g$ first, then $f$. The surjectivity argument pulls back from the outside in as well — $g$ first, then $f$. In both, the *outer* function is used first, which is a useful mnemonic.</div>
</Discussion>

<Proof>
*Injectivity.* Suppose $(g\circ f)(s_1) = (g\circ f)(s_2)$, i.e. $g(f(s_1)) = g(f(s_2))$. As $g$ is injective, $f(s_1) = f(s_2)$; as $f$ is injective, $s_1 = s_2$.

*Surjectivity.* Let $r \in R$. As $g$ is surjective, there is $t \in T$ with $g(t) = r$. As $f$ is surjective, there is $s \in S$ with $f(s) = t$. Then $(g\circ f)(s) = g(t) = r$.
</Proof>

Consequently a composition of bijections is a bijection (§3.8).

## Partial converses

> **Proposition.** Let $f : S \to T$, $g : T \to R$.
> 1. If $g \circ f$ is injective, then $f$ is injective.
> 2. If $g \circ f$ is surjective, then $g$ is surjective.
> 3. Neither conclusion can be strengthened to the other factor.

<Proof>
(1) Suppose $f(s_1) = f(s_2)$. Applying $g$, $(g\circ f)(s_1) = (g\circ f)(s_2)$, so injectivity of the composite gives $s_1 = s_2$.

(2) Let $r \in R$. By surjectivity of $g \circ f$ there is $s \in S$ with $g(f(s)) = r$; then $t := f(s) \in T$ satisfies $g(t) = r$.

(3) Take $S = \{a\}$, $T = \{1,2\}$, $R = \{x\}$, $f(a)=1$, $g(1)=g(2)=x$. Then $g\circ f$ is both injective and surjective, while $g$ is not injective and $f$ is not surjective.
</Proof>

The pattern is worth memorizing: **injectivity of a composite constrains the first map; surjectivity constrains the second.** It generalizes directly — in any category, if $g\circ f$ is monic then $f$ is monic, and if $g \circ f$ is epic then $g$ is epic — and it is the reason retracts and sections behave the way they do.

<Warning title="Domain bookkeeping">
$g \circ f$ requires $\operatorname{cod}(f) = \operatorname{dom}(g)$ *exactly*, not merely $\operatorname{Im}(f) \subseteq \operatorname{dom}(g)$. In practice people compose whenever the outputs fit, quietly shrinking the declared target of $f$ to make it work. This is harmless but worth noticing, because it changes the function (§3.1) and can change whether it is surjective.
</Warning>

## Composition and pre-images

$$
(g\circ f)^{-1}(U) = f^{-1}\big(g^{-1}(U)\big) \quad\text{for } U \subseteq R.
$$

*Symbol by symbol: $\subseteq$ is "sits inside", $\circ$ is "after". So the line reads: tracing back through both machines at once is the same as tracing back through the second, then the first.*

<Proof>
$s \in (g\circ f)^{-1}(U) \iff g(f(s)) \in U \iff f(s) \in g^{-1}(U) \iff s \in f^{-1}(g^{-1}(U))$, each step being the pivot equivalence of §3.3.
</Proof>

Note the reversal of order: tracing back through a composition undoes the second machine first (§3.4). That single line is why so many good properties survive composition — if each machine separately carries well-behaved collections to well-behaved collections, then so does the pair run in sequence.

<Aside>
The bijections from a set $X$ to itself are closed under composition, contain the identity, and contain the inverse of each of their members — the three properties this module proved. A collection of transformations with those three properties is the basic object of abstract algebra, and the bijections of a set are the model case.
</Aside>

Composition is the operation the next two courses are organized around.

**The chain rule is a theorem about composition.**
$$(g\circ f)'(x) = g'\big(f(x)\big)\cdot f'(x).$$

*Symbol by symbol: $\circ$ is "after".*

Note where each function is evaluated — $g'$ at $f(x)$, not at $x$ — and note that this is forced by the definition of composition, not a convention. Most chain-rule errors are misreadings of which function acts first, which is the same right-to-left confusion this module flags.

Composition also structures the integration techniques: $u$-substitution is the chain rule run backwards, and recognizing an integrand as $g'(f(x))f'(x)$ is recognizing a composition.

- $AB$ is defined only when the dimensions match, because $g\circ f$ requires $\operatorname{codom} f = \operatorname{dom} g$.
- $AB \neq BA$ in general, because composition is not commutative — and the counterexample in this module is the same phenomenon.
- $(AB)C = A(BC)$, because composition is associative, proved above in four lines.
- $AI = IA = A$, because the identity is a unit for composition.
- $(AB)^{-1} = B^{-1}A^{-1}$, reversing the order, because inverses of compositions reverse.
