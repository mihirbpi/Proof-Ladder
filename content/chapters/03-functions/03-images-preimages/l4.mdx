## Definitions

Let $f$ be a function from a set $S$ to a set $T$. We write $f(s)$ for the output $f$ gives on the input $s$ — new notation, and worth reading aloud as *"$f$ of $s$"* until it is automatic.

$$
\operatorname{Im}(f) = \{\, f(s) \mid s \in S \,\} \subseteq T
$$

is the **image** — the set of values actually attained. For $U \subseteq T$,

$$
f^{-1}(U) = \{\, s \in S \mid f(s) \in U \,\} \subseteq S
$$

is the **pre-image** of $U$.

The pre-image definition unfolds to the single equivalence that every proof in the next module uses:
$$
s \in f^{-1}(U) \quad\text{exactly when}\quad f(s) \in U. \tag{1}
$$

## Image versus codomain

The codomain $T$ is **declared**; the image is **computed**. Always $\operatorname{Im}(f) \subseteq T$, and equality is a special property with a name (surjectivity, module 3.6).

Take $f(x) = x^2$, a function from $\mathbb{R}$ to $\mathbb{R}$. A square is never negative, and every non-negative number is a square, so
$$
\operatorname{Im}(f) = \{\, y \in \mathbb{R} \mid y \geq 0 \,\},
$$
which is not all of $\mathbb{R}$ — nothing negative is attained.

Take $g(x) = 2^x$, again from $\mathbb{R}$ to $\mathbb{R}$. Powers of $2$ are always positive, so
$$
\operatorname{Im}(g) = \{\, y \in \mathbb{R} \mid y > 0 \,\},
$$
and $0$ itself is never attained, however negative the exponent gets.

Note the word *range* is best avoided: some authors use it for the image, others for the codomain. Say which you mean.

## Worked pre-images: $f(x) = x^2$

Let $f(x) = x^2$, a function from $\mathbb{R}$ to $\mathbb{R}$.

$$
f^{-1}(\{9\}) = \{-3, 3\}.
$$
Two elements — the pre-image of a single point need not be a single point.

$$
f^{-1}(\{3\}) = \{-\sqrt3, \sqrt3\},
\qquad
f^{-1}(\{0\}) = \{0\},
\qquad
f^{-1}(\{-5\}) = \emptyset.
$$

The last one is not an error. No real number squares to $-5$, so nothing lands in $\{-5\}$, and the pre-image is empty. Pre-images of sets outside the image are always empty, and this is normal.

Pre-images of intervals:
$$
f^{-1}\big((-2, 6)\big) = \{x \in \mathbb{R} \mid -2 < x^2 < 6\} = (-\sqrt6, \sqrt6).
$$
The left constraint $-2 < x^2$ is automatic since squares are non-negative; only $x^2 < 6$ bites. Notice the pre-image of an open interval came out as an open interval. That is not a coincidence, and it is the property later courses take as the *definition* of a continuous function.

## Worked pre-images: the floor function

Let $\lfloor \cdot \rfloor$ be the floor function, taking each real number to an integer.

$$
\lfloor \cdot \rfloor^{-1}(\{4\}) = \{x \in \mathbb{R} \mid \lfloor x \rfloor = 4\} = [4, 5).
$$

Half-open, because $4$ has floor $4$ but $5$ has floor $5$. The pre-image of a single integer is an entire interval — infinitely many inputs collapsing to one output.

$$
\lfloor \cdot \rfloor^{-1}(\{4, 5\}) = [4, 6),
\qquad
\lfloor \cdot \rfloor^{-1}(\mathbb{Z}) = \mathbb{R}.
$$

## The link between them

$$
t \in \operatorname{Im}(f) \quad\text{exactly when}\quad f^{-1}(\{t\}) \neq \emptyset.
$$

Both sides say "$t$ is attained", one forwards and one backwards. The proof is immediate from the definitions: $t \in \operatorname{Im}(f)$ means some $s$ has $f(s) = t$, and $f^{-1}(\{t\}) \neq \emptyset$ means some $s$ has $f(s) \in \{t\}$ — the same statement.

The set $f^{-1}(\{t\})$ is called the **fibre** over $t$. The whole of the next three modules can be phrased in terms of fibres:

| Property | Fibre condition |
|---|---|
| function | each $s$ in exactly one fibre |
| injective (3.5) | every fibre has **at most** one element |
| surjective (3.6) | every fibre has **at least** one element |
| bijective (3.8) | every fibre has **exactly** one element |

That table is worth memorising now; it makes the next four modules look like one idea.

<Warning title="f⁻¹ here is not an inverse function">
$f^{-1}(U)$ is defined for **every** function $f$, with no hypotheses at all. It takes a *subset of $T$* and returns a *subset of $S$*.

An inverse *function*, written the same way but going from $T$ back to $S$, takes an element and returns an element, and exists only when $f$ is a bijection (module 3.9). With $f(x) = x^2$ on $\mathbb{R}$, the pre-image $f^{-1}(\{9\}) = \{-3,3\}$ exists, while no inverse function does.

The notation is unfortunate and universal. Distinguish them by what goes in: a set means pre-image, an element means inverse function.
</Warning>

<Aside>
Images misbehave where pre-images do not. $f(A \cap B) \subseteq f(A) \cap f(B)$, but equality can fail: with $f(x)=x^2$, $A = \{2\}$, $B = \{-2\}$, the left side is $f(\emptyset) = \emptyset$ while the right side is $\{4\}$. Module 3.4 shows pre-images have no such defect, which is why so many definitions in analysis and topology are stated with $f^{-1}$.
</Aside>
