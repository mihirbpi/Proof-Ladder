## Definitions

Let $f$ be a function from a set $S$ to a set $T$. We write $f(s)$ for the output $f$ gives on the input $s$ — new notation, and worth reading aloud as *"$f$ of $s$"* until it is automatic.

$$
\operatorname{Im}(f) = \{\, f(s) \mid s \in S \,\} \subseteq T
$$

*Symbol by symbol: $\subseteq$ is "sits inside", $\in$ is "is in", the bar $\mid$ is "such that". So the line reads: the image is **everything $f$ actually produces**, as $s$ runs over the whole domain — and it sits inside $T$.*

is the **image** — the values $f$ actually attains. And for a collection $U$ of targets,

$$
f^{-1}(U) = \{\, s \in S \mid f(s) \in U \,\} \subseteq S
$$

*Symbol by symbol: $\subseteq$ is "sits inside", $\in$ is "is in", the bar $\mid$ is "such that". So the line reads: tracing back from $U$ collects **every input whose output lands in $U$** — and those inputs sit inside $S$.*

is the **pre-image** of $U$.

That definition unfolds to the one line every proof in the next module uses:
$$
s \in f^{-1}(U) \quad\text{exactly when}\quad f(s) \in U. \tag{1}
$$

*Symbol by symbol: $\in$ is "is in". So the line reads: a thing is in the traced-back set exactly when its output lands inside $U$.*

## Image versus codomain

The codomain is **declared**; the image is **computed**. The image always sits inside the codomain, and the two being equal is a special property with a name (surjectivity, module 3.6).

Take squaring, as a function from the numbers on the line to themselves. A square is never negative, and every non-negative number is somebody's square — so the image is exactly the numbers that are zero or bigger, which is **not** the whole codomain. Nothing negative is ever attained.

Take $g(x) = 2^x$ instead. Powers of $2$ are always positive, so its image is the numbers **strictly** bigger than zero — and $0$ itself is never reached, however negative the exponent gets.

Avoid the word *range*: some authors use it for the image and others for the codomain. Say which you mean.

## Worked pre-images: $f(x) = x^2$

Let $f$ be squaring again.

$$
f^{-1}(\{9\}) = \{-3, 3\}.
$$
Two elements — the pre-image of a single point need not be a single point.

$$
f^{-1}(\{3\}) = \{-\sqrt3, \sqrt3\},
\qquad
f^{-1}(\{0\}) = \{0\},
\qquad
f^{-1}(\{-5\}) = \emptyset.
$$

*Symbol by symbol: $\emptyset$ is the empty collection. So the line reads: tracing back from $3$ gives its two square roots, tracing back from $0$ gives just $0$, and tracing back from $-5$ gives nothing at all.*

The last one is not an error. No real number squares to $-5$, so nothing lands in $\{-5\}$, and the pre-image is empty. Pre-images of sets outside the image are always empty, and this is normal.

### Tracing back from an interval

Pre-images of intervals:
$$
f^{-1}\big((-2, 6)\big) = \{x \in \mathbb{R} \mid -2 < x^2 < 6\} = (-\sqrt6, \sqrt6).
$$

*Symbol by symbol: $\mathbb{R}$ is the real numbers, $\in$ is "is in", the bar $\mid$ is "such that". So the line reads: tracing back from that interval gives the numbers whose square lies between $-2$ and $6$ — which is everything strictly between $-\sqrt6$ and $\sqrt6$.*

The left constraint $-2 < x^2$ is automatic since squares are non-negative; only $x^2 < 6$ bites. Notice the pre-image of an open interval came out as an open interval. That is not a coincidence. Much later, when courses need to say exactly what it means for a graph to have no breaks in it, this is the property they end up using — the pre-image of an interval with open ends is again one. You are not expected to make anything of that yet.

## Worked pre-images: the floor function

Let $\lfloor \cdot \rfloor$ be the floor function, taking each real number to an integer.

$$
\lfloor \cdot \rfloor^{-1}(\{4\}) = \{x \in \mathbb{R} \mid \lfloor x \rfloor = 4\} = [4, 5).
$$

*Symbol by symbol: $\mathbb{R}$ is the real numbers, $\in$ is "is in", the bar $\mid$ is "such that". So the line reads: tracing back from $4$ collects every real number whose floor is $4$ — everything from $4$ up to but not including $5$.*

Half-open, because $4$ has floor $4$ but $5$ has floor $5$. The pre-image of a single integer is an entire interval — infinitely many inputs collapsing to one output.

$$
\lfloor \cdot \rfloor^{-1}(\{4, 5\}) = [4, 6),
\qquad
\lfloor \cdot \rfloor^{-1}(\mathbb{Z}) = \mathbb{R}.
$$

*Symbol by symbol: $\mathbb{Z}$ is the integers, $\mathbb{R}$ is the real numbers. So the line reads: trace back from $\{4,5\}$ and you get everything from $4$ up to but not including $6$.*

## The link between them

$$
t \in \operatorname{Im}(f) \quad\text{exactly when}\quad f^{-1}(\{t\}) \neq \emptyset.
$$

*Symbol by symbol: $\in$ is "is in", $\emptyset$ is the empty collection. So the line reads: a target is in the image exactly when at least one input lands on it.*

Both sides say *something lands on $t$*, one looking forward and one looking back. The proof is immediate from the definitions: being in the image means some input has $f$ of it = t$, and $f^{-1}(\{t\}) \neq \emptyset$ means some $s$ has $f(s) \in \{t\}$ — the same statement.

The pre-image of a **single** output, $f^{-1}(\{t\})$, is worth looking at on its own: it is everything that lands on the one point $t$. The whole of the next three modules can be phrased in terms of those sets:

| Property | Condition on what lands where |
|---|---|
| function | each input lands on exactly one output |
| injective (3.5) | **at most** one input lands on each output |
| surjective (3.6) | **at least** one input lands on each output |
| bijective (3.8) | **exactly** one input lands on each output |

That table is worth memorizing now — it makes the next four modules look like one idea rather than four.

<Warning title="f⁻¹ here is not an inverse function">
The traced-back set is defined for **every** function, with no conditions at all: it takes a *collection* of targets and returns a *collection* of inputs.

An inverse *function*, written the same way, takes a single target and returns a single input — and exists only when $f$ is a bijection (module 3.9). With $f(x) = x^2$ on $\mathbb{R}$, the pre-image $f^{-1}(\{9\}) = \{-3,3\}$ exists, while no inverse function does.

The notation is unfortunate and universal. Distinguish them by what goes in: a set means pre-image, an element means inverse function (§3.9: the rule that undoes it).
</Warning>

<Aside>
Images misbehave where traced-back sets do not. The image of an overlap always sits inside the overlap of the images, but the two can differ: with squaring, $A = \{2\}$ and $B = \{-2\}$, the left side is $f(\emptyset) = \emptyset$ while the right side is $\{4\}$. Module 3.4 shows pre-images have no such defect, which is why so many later definitions are stated in terms of tracing back rather than going forwards.
</Aside>
