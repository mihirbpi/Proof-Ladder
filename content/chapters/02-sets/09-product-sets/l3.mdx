Every element you have met so far has been a single thing. This module builds elements out of *two* things, and that turns out to be how coordinates, graphs, and eventually functions all get made.

## Ordered pairs

An **ordered pair** is two objects in slots, written with round brackets:
$$
(3, 7), \qquad (\text{red shirt}, \text{party hat}).
$$

The word *ordered* is the whole point. The first slot and the second slot have different jobs, so
$$
(3, 7) \neq (7, 3).
$$

Two ordered pairs are equal only when they match slot by slot:
$$
(a, b) = (c, d) \quad\text{exactly when}\quad a = c \text{ and } b = d.
$$

Compare this with sets, where $\{3,7\} = \{7,3\}$ because order is invisible. Pairs are the opposite: order is everything. When you need order, you use pairs, not sets.

## The product set

Given two sets $S$ and $T$, the **product set** $S \times T$ is the set of *all* ordered pairs with first slot from $S$ and second slot from $T$:
$$
S \times T = \{\, (s, t) \mid s \in S \text{ and } t \in T \,\}.
$$

Example. Let $S = \{1, 2\}$ and $T = \{a, b, c\}$. Then
$$
S \times T = \{(1,a), (1,b), (1,c), (2,a), (2,b), (2,c)\},
$$
six pairs. Laid out as a grid, $S$ gives the rows and $T$ the columns:

|  | $a$ | $b$ | $c$ |
|---|---|---|---|
| $1$ | $(1,a)$ | $(1,b)$ | $(1,c)$ |
| $2$ | $(2,a)$ | $(2,b)$ | $(2,c)$ |

## Counting

The grid explains the count. If $S$ has $m$ elements and $T$ has $n$, then $S \times T$ has $m$ rows and $n$ columns, so
$$
m \times n \text{ elements.}
$$
That is where the name *product* comes from, and it is the reason multiplication counts things: multiplication *is* the size of a grid.

## Order matters, so $S \times T \neq T \times S$

With the sets above, $T \times S$ contains $(a, 1)$ — a letter first, then a number. But $S \times T$ contains $(1, a)$. These are different pairs, so the two product sets are different, even though they have the same size.

## Anything times the empty set is empty

$$
S \times \emptyset = \emptyset.
$$

Why? To build an element of $S \times \emptyset$ you would need a first slot from $S$ and a second slot from $\emptyset$. But $\emptyset$ has nothing to offer, so the second slot can never be filled, so no pair can ever be built.

Compare it with the grid: $\emptyset$ contributes zero columns, and a grid with zero columns has no boxes, however many rows it has. Which is also why $m \times 0 = 0$.

## Coordinates are a product set

Here is the payoff. Graph paper is a product set.

A point on the grid is named by a pair: $(3, 2)$ means three across and two up. The set of all such points with whole-number coordinates is
$$
\mathbb{Z} \times \mathbb{Z},
$$
and the set of all points in the plane, coordinates allowed to be any number on the number line, is
$$
\mathbb{R} \times \mathbb{R}.
$$

That set is written $\mathbb{R}^2$ and is exactly what you have been drawing on since you first met the $x$-axis. The point $(3,2)$ and the point $(2,3)$ are in different places — which is the same fact as $(a,b) \neq (b,a)$, now with a picture attached.

<Warning title="Round brackets do double duty">
$(1, 5)$ can mean an ordered pair, or the interval of all numbers strictly between $1$ and $5$ (module 2.2). Nothing but context distinguishes them. If the discussion is about points in the plane, it is a pair; if it is about a stretch of the number line, it is an interval.
</Warning>

<Aside>
Products can be stacked: $S \times T \times R$ holds ordered *triples* $(s, t, r)$, and $\mathbb{R}^3$ is how you name a point in space. The pattern keeps going, and $\mathbb{R}^n$ is the setting for essentially all of higher mathematics.
</Aside>
