## Definition

$A$ is a **subset** of $S$ when every member of $A$ is also a member of $S$. It is written

$$A \subseteq S$$

*Symbol by symbol: $\subseteq$ is "sits inside". So the line reads: everything in $A$ is also in $S$.*

Read that as an if–then claim made about every object at once: **if a thing is in $A$, then it is in $S$.**

That reading is the whole module. Module 1.12 already told you how to prove such a claim (**take any one and follow it**) and how to refute one (**one bad apple** — produce a single thing that is in $A$ and not in $S$).

## Element chasing

The technique has a name: **element chasing**. Its shape is fixed.

> Take any member of $A$. … [reason] … Therefore it is in $S$. Nothing was assumed about which member we took, so all of $A$ sits inside $S$.

Everything between the first sentence and the last uses only what membership in $A$ guarantees. The moment you assume more, the proof is broken.

> **Proposition.** Let $S$ be the numbers strictly between $-3$ and $5$, and let $T$ be the numbers strictly above $-6$ and up to and including $5$. Then $S$ sits inside $T$.

<Discussion>
  <div slot="know">Being in $S$ means $-3 < x < 5$. Being in $T$ means $-6 < x \leq 5$.</div>
  <div slot="want">Both halves of that second condition.</div>
  <div slot="how">Chase the element. From $-3 < x$ and $-6 < -3$, transitivity gives $-6 < x$. From $x < 5$ we get $x \leq 5$, since strict inequality implies the weak one.</div>
</Discussion>

<Proof>
Take any number $x$ in $S$, so $-3 < x < 5$.

Since $-6 < -3$ and $-3 < x$, we get $-6 < x$.

And since $x < 5$, certainly $x \leq 5$.

So $-6 < x \leq 5$, which puts $x$ in $T$. Nothing was assumed about which number we took, so all of $S$ sits inside $T$.
</Proof>

Note that $T$ is strictly bigger: $5$ is in $T$ and not in $S$. Showing that takes an actual example — the subset proof above does not prove it on its own.

## Refuting a subset claim

The other direction is false: $T$ does **not** sit inside $S$. To show that, produce one thing — the number $5$, which is in $T$ and not in $S$. Done. A single counterexample refutes a claim about everything.

<Warning title="Being an element versus being a subset">
The number $2$ is a **member** of $\{1,2,3\}$. The set $\{2\}$ **sits inside** $\{1,2,3\}$.

Those are different statements about different things, and swapping them produces nonsense: $2$ cannot sit inside anything, because $2$ is not a collection, and $\{2\}$ is not a member of $\{1,2,3\}$, whose members are three numbers.

The distinction gets sharper when sets contain sets. Take $A = \{1, \{2,3\}\}$ — a collection with exactly two members, the number $1$ and the set $\{2,3\}$:

| statement | |
|---|---|
| $1$ is a member of $A$ | ✓ |
| $\{2,3\}$ is a member of $A$ | ✓ |
| $2$ is a member of $A$ | ✗ — $2$ is a member of a member |
| $\{2,3\}$ sits inside $A$ | ✗ — that would need $2$ and $3$ to be members |
| $\{1\}$ sits inside $A$ | ✓ |
</Warning>

## The empty set sits inside every set, with nothing to check

> **Proposition.** The empty set sits inside every set.

<Proof>
We have to show that every member of the empty set is a member of $S$.

Take any object at all. The *if* part — that it is in the empty set — is false, because the empty set has no members. An if–then claim whose *if* part is false is true (module 1.5). So the claim holds for that object, and the object was any object at all.
</Proof>

This is the first place where a true-because-empty claim does real work rather than turning up as a curiosity. Refuse it and the empty set becomes an exception to nearly every theorem in this chapter. Accept it and everything stays uniform.

## Every set sits inside itself, and chains pass along

Every set sits inside itself, for the shortest possible reason: anything in $S$ is in $S$.

> **Proposition.** If $A$ sits inside $B$, and $B$ sits inside $C$, then $A$ sits inside $C$.

<Proof>
Take any member of $A$. Since $A$ sits inside $B$, it is in $B$. Since $B$ sits inside $C$, it is in $C$. Nothing was assumed about which member we took, so $A$ sits inside $C$.
</Proof>

Those two facts — every set sits inside itself, and sitting-inside chains — together with *two sets that sit inside each other are equal* (module 2.6) are exactly the properties $\leq$ has on numbers. So **sitting inside orders sets the way $\leq$ orders numbers**, with one difference worth noticing: any two numbers can be compared, while $\{1,2\}$ and $\{2,3\}$ sit inside each other in neither direction. Some pairs simply cannot be ranked.

## Proper subsets

$A$ is a **proper subset** of $S$ when it sits inside $S$ *and* is not all of $S$ — when $S$ has something $A$ does not.

The notation for this varies between books, and the variation is a genuine trap: some write $A \subset S$ to mean proper, and others write the same mark to mean ordinary sitting-inside. When you read a new book, check which one it means before trusting a line that uses it.

## Why every containment is now a theorem

Module 2.1 said that the counting numbers sit inside the integers, which sit inside the fractions, which sit inside all the numbers on the line. Every one of those is now a claim that owes you a proof. Here is one:

> **The integers sit inside the fractions.** Take any integer $n$. Then $n = \tfrac{n}{1}$ — a whole number over a whole number, with the bottom not zero — so $n$ is a fraction. Nothing was assumed about $n$, so every integer is a fraction.

Each containment is also strict, and one example each shows it: $-1$ is an integer and not a counting number; $\tfrac12$ is a fraction and not an integer; and $\sqrt2$ is on the number line and is not a fraction — that last one needing the genuinely hard proof of module 4.7.

<Aside>
Collect **all** the subsets of $S$ into one set and you get the **power set** of $S$ — module 6.7 counts them.

For $S = \{a,b\}$ that collection is $\{\,\}$, $\{a\}$, $\{b\}$ and $\{a,b\}$ — four members, each of them a set. A set of $n$ things has $2^n$ subsets, which module 6.3 proves by induction.

A set always has strictly more subsets than members — even when it has infinitely many members. Module 6.7 proves it, and that is where "there is no biggest infinity" comes from.
</Aside>
