Some sets sit inside others. Every square is a rectangle. Every counting number is somewhere on the number line. This relationship has a name, a symbol, and — much more importantly — a proof technique that the whole of set theory runs on.

## The definition

$A$ is a **subset** of $S$, written
$$A \subseteq S,$$
if every element of $A$ is also an element of $S$.

Examples:

- $\{2, 4\} \subseteq \{1, 2, 3, 4, 5\}$ ✓
- $\{2, 7\} \subseteq \{1, 2, 3, 4, 5\}$ ✗ — because $7$ is in the first and not the second.
- (squares) $\subseteq$ (rectangles) ✓ — every square is a rectangle.
- (rectangles) $\subseteq$ (squares) ✗ — because a $2$-by-$5$ rectangle is a rectangle and not a square.

Notice that one bad element is enough to destroy a subset claim. That is module 1.11 again: a subset claim is a *for all* claim, so a single counterexample kills it.

## The proof move: take any one and follow it

Because $A \subseteq S$ says something about *every* element of $A$, you cannot prove it by checking a few. You prove it the way module 1.12 taught: **take any one and follow it.**

Reach into $A$ and pull out something. Do not pick a favourite — take whatever your hand lands on. Then follow it, using only what being in $A$ guarantees, until it arrives in $S$.

> **Claim.** Every square is a rectangle.

<Discussion>
  <div slot="know">A square is a four-sided shape with four square corners and four equal sides. A rectangle is a four-sided shape with four square corners.</div>
  <div slot="want">Whatever square we picked is a rectangle.</div>
  <div slot="how">Take any one and follow it. Unfold what "square" gives us, and check it is enough to be a rectangle.</div>
</Discussion>

<Proof>
Take any square. Do not pick a particular one — take whichever square you like.

Being a square, it has four sides, four square corners, and four equal sides.

To be a rectangle, a shape needs four sides and four square corners. The one you picked has both.

So the shape you picked is a rectangle. And we never used anything about *which* square it was — only that it was a square. So every square is a rectangle.
</Proof>

Read that proof again and notice how it starts and ends. It starts with "take any square", and it ends by pointing out that nothing special was assumed. That frame is what turns one argument into infinitely many.

## The empty set is a subset of everything

$$\emptyset \subseteq S \quad \text{for every set } S.$$

This feels wrong the first time. Here is why it is right. To break the claim, you would have to produce something in $\emptyset$ that is not in $S$. But $\emptyset$ has nothing in it, so you can never produce one, so you can never break the claim.

It is the umbrella promise from module 1.5 all over again: a promise about rainy days is unbroken on a sunny day. A promise about elements of $\emptyset$ is unbroken because there are none.

## Every set is a subset of itself

$S \subseteq S$, always: everything in $S$ is in $S$. True and boring, but it matters — it is why "subset" does not mean "smaller."

If you want to insist that $A$ is inside $S$ *and* different from it, say $A$ is a **proper subset** of $S$.

## Subsets chain

> **Claim.** If $A \subseteq B$ and $B \subseteq C$, then $A \subseteq C$.

<Proof>
Take any one thing out of $A$ and follow it.

Since $A \subseteq B$, everything in $A$ is in $B$. So the thing you picked is in $B$.

Since $B \subseteq C$, everything in $B$ is in $C$. So the thing you picked is in $C$.

We started in $A$ and arrived in $C$, using nothing special about what we picked. So $A \subseteq C$.
</Proof>

A relation that chains down the line like this is called **transitive**.

You use it constantly when sorting shapes: squares are inside rectangles, and rectangles are inside quadrilaterals, so squares are inside quadrilaterals — with no extra checking. That is transitivity doing real work, and it is exactly the shape hierarchy you build in geometry.

<Warning title="∈ and ⊆ are different symbols">
$2 \in \{1,2,3\}$ — the number $2$ is an *element*.

$\{2\} \subseteq \{1,2,3\}$ — the *set* $\{2\}$ is a subset.

$2 \subseteq \{1,2,3\}$ is nonsense: $2$ is not a set. $\{2\} \in \{1,2,3\}$ is false: the things inside $\{1,2,3\}$ are numbers, not boxes. Mixing these two symbols up is the most common error in this chapter.
</Warning>

<Aside>
Taking any one and following it is *the* technique of set theory. Almost every proof in this chapter is one, and several are two of them back to back (module 2.6). Once you can write it fluently, most of Chapter 2 is bookkeeping.
</Aside>
