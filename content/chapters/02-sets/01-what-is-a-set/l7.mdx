Chapter 1 supplied a language for making claims. This chapter supplies the objects the claims are about. The organising fact is that mathematics has settled on a single kind of object — the set — from which numbers, functions, relations, spaces, and groups are all constructed.

A **set** is a well-defined collection of objects, its **elements**. The membership relation is written
$$
x \in S, \qquad x \notin S,
$$
and for every object $x$ and set $S$, "$x \in S$" is a statement in the sense of §1.1: it has a definite truth value.

## Extensionality

The governing principle is that **a set is determined by its elements and nothing else**:
$$
S = T \quad\Longleftrightarrow\quad \forall x\;(x \in S \Leftrightarrow x \in T).
$$

Everything idiosyncratic about sets follows:

- $\{1,2,3\} = \{3,2,1\}$: sets carry no order.
- $\{1,1,2\} = \{1,2\}$: sets carry no multiplicity.
- $\{x \in \mathbb{R} \mid x^2 = 1\} = \{1, -1\}$: how a set is *described* is irrelevant to what it *is*.

The last point deserves emphasis. Two wildly different descriptions may denote the same set, and proving that they do is often the entire content of a theorem. The trigonometric identity $\{x \mid \sin x = 0\} = \{n\pi \mid n \in \mathbb{Z}\}$ is such a statement.

Note also that extensionality is what makes §2.6's double-inclusion method correct: since $S = T$ means the two membership conditions are equivalent, and an equivalence is two implications (§1.9), a set equality is exactly two subset proofs.

## Well-definedness, and what it is protecting against

A collection qualifies as a set only when membership is unambiguous for every candidate object. "The set of large integers" fails: "$10^6$ is large" is not a statement, so nothing about the collection can be proved.

But the requirement is doing far more work than excluding vague adjectives. Suppose every describable collection were a set. Define
$$
R = \{x \mid x \notin x\}.
$$
Then $R \in R \Leftrightarrow R \notin R$ — a contradiction with no escape route. This is **Russell's paradox** (1901), and it destroyed Frege's foundations of arithmetic while the second volume was in press.

The modern repair is that unrestricted comprehension is not permitted. In Zermelo–Fraenkel set theory you may not form $\{x \mid p(x)\}$ out of nothing; you may only *separate* a subcollection out of a set you already have:
$$
\{x \in A \mid p(x)\} \quad\text{is a set, whenever $A$ is.}
$$
Run Russell's construction under this restriction and you get, for any set $A$, that $R_A = \{x \in A \mid x \notin x\} \notin A$ — no contradiction, just the useful theorem that no set contains everything.

<Warning title="Distinguish three objects">
$0$ is a number. $\emptyset$ is the set with no elements. $\{\emptyset\}$ is a set with exactly one element, that element being $\emptyset$. So $|\emptyset| = 0$ but $|\{\emptyset\}| = 1$, and $\emptyset \in \{\emptyset\}$ while $\emptyset \notin \emptyset$.

The distinction is not pedantry: the von Neumann construction of the naturals is $0 := \emptyset$, $1 := \{\emptyset\}$, $2 := \{\emptyset, \{\emptyset\}\}$, and if you cannot keep these apart the construction is unreadable.
</Warning>

## The empty set is unique

There is exactly one empty set. Suppose $\emptyset_1$ and $\emptyset_2$ both have no elements. By extensionality they are equal iff $\forall x\,(x \in \emptyset_1 \Leftrightarrow x \in \emptyset_2)$. Both sides of the biconditional are false for every $x$, so the biconditional holds vacuously (§1.5) for every $x$, so the sets are equal. The article in "*the* empty set" is earned, not assumed — and note that the argument is a small piece of vacuous reasoning doing real work.

## The standard number systems

$$
\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R} \subseteq \mathbb{C}
$$

Each is constructed to repair a failure of closure in its predecessor: $\mathbb{Z}$ makes subtraction total, $\mathbb{Q}$ makes division by nonzero elements total, $\mathbb{R}$ fills the order-theoretic gaps ($\sqrt 2 \notin \mathbb{Q}$, §4.7), $\mathbb{C}$ makes every non-constant polynomial have a root. Chapter 4 treats the algebraic structure of these; Chapter 5 builds $\mathbb{C}$; Chapter 7 builds $\mathbb{N}$ from nothing.

Strictly, the containments are abuses of notation: the integer $3$ and the rational $3/1$ and the real $3.000\ldots$ are constructed as different objects, and what actually holds is that each system embeds canonically in the next. Everyone writes $\subseteq$ and identifies along the embeddings. It is worth knowing that this is what is being done.

## "Set" is a primitive

"A well-defined collection" is not a definition — *collection* is a synonym. This is unavoidable and deliberate. Any axiomatic theory must begin with undefined primitives; in ZF these are "set" and "$\in$", and their meaning is fixed not by definition but by the axioms they satisfy. Chapter 7 does the same for $\mathbb{N}$: *zero* and *successor* go undefined, and the Peano axioms pin down their behaviour.

This is the mature attitude toward mathematical objects generally. What a set *is* turns out to matter far less than what can be proved about it.

<WhereThisGoes level="l7">
Set language is the notation both of the courses ahead are written in, and the fluency built here is what makes their definitions short.

**In calculus, every domain is a set and every domain matters.** The domain of $\ln x$ is $(0,\infty)$; the domain of $\sqrt{x^2-4}$ is $(-\infty,-2]\cup[2,\infty)$; the interval of convergence of a power series is a set determined by the radius plus a separate check at each endpoint. Theorems are stated over sets too — the Extreme Value Theorem needs a *closed, bounded* interval, and both adjectives are conditions on a set rather than on the function.

The solution set of an inequality, the level set of a function, the set of critical points, the set where a series converges: each is an object you compute, and each is described by a membership condition.

**In linear algebra, the objects themselves are sets with structure.** A subspace is a set closed under two operations. The span of a collection is a set. The null space is $\{\mathbf{x} : A\mathbf{x}=\mathbf{0}\}$ and the column space is a set of outputs — and the two live in different spaces, which the notation makes visible and words do not.

The one habit worth carrying forward from this module is the insistence that a set is determined by its members. That is what licenses proving two differently-described sets equal by showing they have the same elements — which is how you will show that the null space of $A$ equals the null space of its reduced row echelon form, and how nearly every structural fact in the subject is established.
