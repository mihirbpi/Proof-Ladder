Chapter 1 gave us statements. This chapter gives us the objects statements are about. The remarkable fact — and one worth noticing before the details bury it — is that essentially every object in mathematics can be built from this one notion.

A **set** is a well-defined collection of objects, called its **elements**. Membership is written with $\in$:
$$
x \in S \quad\text{($x$ is an element of $S$)}, \qquad x \notin S \quad\text{($x$ is not)}.
$$

*Symbol by symbol: $\notin$ is "is not in", $\in$ is "is in". So the line reads: the first says $x$ is one of the things in $S$; the second says it is not.*

For each object $x$ and set $S$, "$x \in S$" is a statement in the sense of module 1.1: definitely true or definitely false.

## Listing notation

$$
D_{20} = \{1, 2, 4, 5, 10, 20\}, \qquad D_{24} = \{1, 2, 3, 4, 6, 8, 12, 24\}
$$

*These are the divisor collections of $20$ and of $24$ — every whole number that goes into each exactly.*

## Sets are determined by their elements

This single principle — **a set is exactly its members** — generates the two facts that surprise everybody:

**Order is irrelevant.** $\{1, 2, 3\} = \{3, 1, 2\}$. A set is not a list; it has no first element.

**Repetition is irrelevant.** $\{1, 1, 2\} = \{1, 2\}$. A set is not a tally; it records membership, not multiplicity.

If you need order, you want an ordered pair or a sequence (module 2.9). If you need counts, you want a multiset. Sets deliberately forget both.

## Well-definedness

A collection is a set only if, for every object, membership is unambiguous.

- the even integers — well defined.
- "the set of large numbers" — not a set. Is $10^6$ large? The question has no mathematical answer, so "$10^6 \in S$" is not a statement, so $S$ is not a set.

This is a real requirement, not a stylistic preference: if membership isn't a statement, no proof about the collection can get started.

## The empty set

The **empty set**, written $\emptyset$, is the set with nothing in it:

$$\emptyset = \{\,\}$$

*Symbol by symbol: $\emptyset$ is the empty collection. So the line reads: the empty set is the set with nothing at all in it.*

is the set with no elements. It exists, it is unique, and it is not the number $0$.

<Warning title="Three things that are not the same">
$0$ — a number.
$\emptyset$ — a set with no elements.
$\{\emptyset\}$ — a set with exactly **one** element, namely $\emptyset$.

The last two get confused constantly. One is an empty box; the other is a box with an empty box inside it.
</Warning>

## The standard number sets

Each number system gets a single blackboard letter as its name. These are shorthand, not new mathematics — read them as *"the naturals"*, *"the integers"*, $\mathbb{Q}$ as *"the rationals"* and $\mathbb{R}$ as *"the reals"*.

| Symbol | Name | Description |
|---|---|---|
| $\mathbb{N}$ | naturals | $\{0, 1, 2, 3, \ldots\}$ |
| $\mathbb{Z}$ | integers | $\{\ldots, -2, -1, 0, 1, 2, \ldots\}$ |
| $\mathbb{Q}$ | rationals | all $\tfrac{p}{q}$ with $p, q \in \mathbb{Z}$, $q \neq 0$ |
| $\mathbb{R}$ | reals | every point on the number line |

These nest: every natural number is an integer, every integer is a rational ($n = \tfrac{n}{1}$), every rational is real. Module 2.3 turns "nest" into the precise notion of a subset, and each of these containments becomes something you can prove rather than say.

### Why each one exists

Each system is built to fix something the one before it cannot do. The counting numbers cannot subtract freely — $3 - 5$ escapes them — so the integers were built. The integers cannot divide freely ($3 \div 5$ escapes it), so $\mathbb{Q}$ was built. $\mathbb{Q}$ has gaps — no rational squares to $2$, as module 4.7 proves — so $\mathbb{R}$ was built. And $\mathbb{R}$ cannot solve $x^2 = -1$, which is why Chapter 5 builds $\mathbb{C}$, the **complex numbers**. The pattern is the same every time: a legitimate operation escapes the system, so the system is enlarged.

<Aside>
Whether $0$ counts as a natural number is a convention. Set theorists and computer scientists say yes; many number theorists say no. This course says yes. When reading elsewhere, check — it changes the statements of theorems, not their content.
</Aside>

## "Set" is left undefined on purpose

Notice that "a well-defined collection of objects" is not really a definition: *collection* is just a synonym for *set*. This is deliberate. Every mathematical theory has to start with undefined undefined starting words, or definitions would chain of *why* forever. In set theory the undefined starting words are "set" and "$\in$", and instead of defining them we state axioms governing how they behave — the same strategy Chapter 7 uses to build $\mathbb{N}$ from the Peano axioms.

The requirement of well-definedness is where the real content hides. Take it too casually — allow *every* describable collection to be a set — and the theory collapses. Consider the collection of all sets that are not elements of themselves. Is it an element of itself? Either answer contradicts the other. This is Russell's paradox, and it is why "well-defined" is doing more work than it looks like.
