A **box** is a bunch of things collected together. Every thing in the world is either **in** the box or **out** of it. There is no maybe.

To make a box, you need a rule everybody agrees on.

- *All the red blocks.* Good rule. You can point at each block and everyone says the same thing.
- *All the nice blocks.* Bad rule! Sam thinks the chipped one is nice. Pip thinks it is junk. Now the box has no edges.

## Give boxes names

Boxes get short names, usually a capital letter. Let's say:

> $A$ is the box with a cat, a dog, and a duck in it.

Now you can talk about $A$ without listing it every time. Handy.

## Three surprising things about boxes

**1. Order does not matter.** A box with a cat, a dog, and a duck is the *same box* as one with a duck, a cat, and a dog. Shake the box. Nothing changed.

**2. Saying it twice does not matter.** If you say "cat, cat, dog," the box still just has a cat and a dog in it. A box does not count how many times you mentioned something. It only knows in or out.

**3. An empty box is still a box.** Tip everything out. What is left? An **empty box**. It has nothing in it, but it is a real box with a real name, and later you will find it surprisingly useful.

<Warning title="A box is not a pile">
A pile can have a cat on top and a duck at the bottom. A box does not care what is on top. The only question a box ever answers is: *is this thing in, or out?*
</Warning>

Line up 5 things. Say a rule out loud. Now sort them into in and out. Then shuffle the "in" pile and ask: is it still the same box? (It is!)
