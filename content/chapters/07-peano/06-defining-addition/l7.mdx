$$
\textbf{(A1)}\ a+0 = a, \qquad \textbf{(A2)}\ a + S(b) = S(a+b).
$$

Recursion on the **second** argument, with the first held fixed. Every asymmetry below traces to that choice.

## Why the definition is legitimate

Writing down a recursion does not by itself define anything: one must know that a function satisfying the clauses exists and is unique.

> **The recursive-definition principle.** Let $A$ be a set, $c \in A$, $f : A \to A$. Then there is a **unique** $h : \mathbb{N}\to A$ with $h(0) = c$ and $h(S(n)) = f(h(n))$.

Uniqueness is an induction: if $h_1, h_2$ both satisfy the clauses, $\{n : h_1(n)=h_2(n)\}$ is inductive, so is all of $\mathbb{N}$ by A9. Existence requires constructing $h$ as a set of pairs and verifying it is a function — also by induction.

Addition is then $a + {-} := h_a$ where $h_a(0) = a$ and $h_a(S(n)) = S(h_a(n))$, i.e. $A = \mathbb{N}$, $c = a$, $f = S$.

So the ninth axiom underwrites not only inductive *proof* but recursive *definition*. Both directions of §6.4's observation — recursion and induction are one structure — are theorems here.

## Derivations

<Proof>
$1+1 = 1+S(0) = S(1+0) = S(1) = 2$.

$2+3 = 2+S(2) = S(2+2) = S(S(2+1)) = S(S(S(2+0))) = S^3(2) = 5$.
</Proof>

> **Proposition.** $a+1 = S(a)$.

<Proof>
$a+1 = a+S(0) = S(a+0) = S(a)$.
</Proof>

This is the theorem §7.3 promised. The notational identification of $S(a)$ with $a+1$, forbidden until addition existed, is now licensed.

## Why $0 + x = x$ needs proof

The definition gives $x + 0 = x$ — zero on the **right**. Zero on the left is a different statement, with no rule producing it, and it must be proved.

**Base case.** $0+0 = 0$ by the first rule with $x=0$. ✓

**Inductive step.** Assume $0+k = k$. Then
$$0 + S(k) = S(0+k) = S(k),$$
using the second rule and then the hypothesis. That is the claim at $S(k)$.

By Axiom 9, $0 + x = x$ for every $x$.

**Four lines to prove that adding zero on the left does nothing.** The proof is short, and the fact that it is needed at all is the point: **the definition is asymmetric**, recursing on the second argument only, so every symmetric-looking fact requires its own argument.

The companion lemma $S(x)+y = S(x+y)$ has the same character — the definition supplies $x + S(y) = S(x+y)$, and the mirror image is a separate induction. Both lemmas are consumed by the proof of commutativity, which is why that proof costs three inductions rather than one.

## The laws, each needing its own induction

None of these is an axiom; each requires induction.

> **Lemma 1.** $0 + a = a$.

  <div slot="know">(A1) gives $a+0=a$; it says nothing about $0+a$, since the recursion peels the second argument.</div>
  <div slot="want">$0+a = a$.</div>
  <div slot="how">Induct on $a$.</div>
</Discussion>

<Proof>
*Base.* $0+0=0$ by (A1). *Step.* $0+S(k) = S(0+k) = S(k)$ by (A2) and (IH).
</Proof>

> **Lemma 2.** $S(a)+b = S(a+b)$.

<Proof>
Induct on $b$. *Base.* $S(a)+0 = S(a) = S(a+0)$. *Step.* $S(a)+S(k) = S(S(a)+k) = S(S(a+k)) = S(a+S(k))$, using (A2), (IH), (A2).
</Proof>

> **Theorem (commutativity).** $a+b = b+a$.

<Proof>
Induct on $b$. *Base.* $a+0 = a = 0+a$ by (A1) and Lemma 1. *Step.* $a+S(k) = S(a+k) = S(k+a) = S(k)+a$, using (A2), (IH), Lemma 2.
</Proof>

> **Theorem (associativity).** $(a+b)+c = a+(b+c)$.

<Proof>
Induct on $c$. *Base.* $(a+b)+0 = a+b = a+(b+0)$. *Step.*
$$(a+b)+S(k) = S\big((a+b)+k\big) = S\big(a+(b+k)\big) = a + S(b+k) = a+(b+S(k)),$$
by (A2), (IH), (A2) twice.
</Proof>

> **Theorem (cancellation).** $a + c = b + c \Rightarrow a = b$.

<Proof>
Induct on $c$. *Base.* Immediate from (A1). *Step.* $a+S(k) = b+S(k)$ gives $S(a+k) = S(b+k)$, so $a+k = b+k$ by **A8** (injectivity of $S$), and (IH) gives $a=b$.
</Proof>

So $+$ on $\mathbb{N}$ is commutative and associative, has $0$ as identity, and permits cancellation — and note that cancellation is where A8 is finally spent. Every axiom now has a job.

<Warning title="Familiarity is not derivation">
Nothing in (A1)–(A2) gives $a+b=b+a$; the definition is manifestly asymmetric. Three inductions were required.

The general discipline: in an axiomatic development, the question is never whether a statement is obvious but whether it has been derived. Chapters 1–6 used commutativity freely, and were — strictly — incomplete until this module.
</Warning>

<Aside>
Had addition been defined by recursion on the first argument, Lemma 1 would be immediate and (A1) would need proof. The asymmetry lives entirely in the definition, and commutativity is exactly the theorem that the operation does not inherit it.

Chapter 4's assumptions are now discharged for $\mathbb{N}$: closure under $+$ is (A1)–(A2), associativity and commutativity are above, and the distributive law follows in §7.7. The arithmetic rules of §4.1 are theorems here.
</Aside>

<WhereThisGoes level="l7">

Defining a thing by saying what it does at the first step and how each step follows from the last is a pattern you will use constantly, and the guarantee that it terminates is always the same one.

**Sequences given by a rule from the previous term are everywhere.** Start at $1$ and repeatedly replace $a$ by $\tfrac12(a + \tfrac2a)$ and the numbers close in on $\sqrt2$ fast — that is how a calculator does it. Every such definition is legitimate for the reason this module gives: each step reaches back to a smaller index, and the counting numbers cannot descend forever.

**Proofs about them are inductions**, and the proof mirrors the definition exactly. To show the terms stay below some bound, you show the first one does and that each step preserves it.

**The commutativity result is the module's real lesson.** The definition builds on the second slot only, so $x + y = y + x$ is not free — it is a theorem, and it takes a proof by induction. A fact this obvious needing an argument is the point: *obvious* and *proved from the definition* are different things.

**Order was defined, not assumed.** Saying $x\leq y$ means *you can get from $x$ to $y$ by adding something*, and every property of $\leq$ follows from that. Getting the ordering free from the arithmetic is one of the tidier surprises here.

</WhereThisGoes>
