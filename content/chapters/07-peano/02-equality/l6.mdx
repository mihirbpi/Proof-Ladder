Your two-column proofs quote these constantly:

> *Reflexive Property of Congruence.* $\overline{AB}\cong\overline{AB}$.
>
> *Symmetric Property of Equality.* If $a=b$ then $b=a$.
>
> *Transitive Property.* If $a=b$ and $b=c$ then $a=c$.

Your book lists them without explaining why these three, or where they come from. This module answers both questions.

## The first four axioms

Peano's system takes them as **axioms**. For all $x, y, z$ in $\mathbb{N}$:

> **Axiom 1 (Reflexive).** $x = x$.
>
> **Axiom 2 (Symmetric).** If $x = y$, then $y = x$.
>
> **Axiom 3 (Transitive).** If $x = y$ and $y = z$, then $x = z$.
>
> **Axiom 4 (Closure).** If $x = y$ and $x$ is a natural number, then so is $y$.

Nothing here says what equality *is*. The axioms describe how it behaves, which is all any proof ever uses — the same strategy as leaving *point* and *line* undefined.

Axiom 4 looks like bookkeeping and is not. It says equality never carries you out of the system: two names for the same thing name the same kind of thing. Without it, substituting equals for equals could produce something that is not a number.

## Equivalence relations

A relation with the first three properties is an **equivalence relation**. Equality is one. It is not the only one, and the others are what make the concept worth naming.

**Congruence of segments.** $\overline{AB}\cong\overline{AB}$ ✓, symmetric ✓, transitive ✓. Your book lists all three, and now you know why exactly three.

**Similarity of triangles.** Same three properties.

**Leaving the same remainder on division by $n$.** From module 4.4: reflexive since $a$ and $a$ have the same remainder, symmetric, and transitive.

**Same age.** Reflexive, symmetric, transitive.

### Relations that fail

| Relation | R | S | T |
|---|---|---|---|
| $=$ | ✓ | ✓ | ✓ |
| $\cong$ | ✓ | ✓ | ✓ |
| $\leq$ | ✓ | ✗ | ✓ |
| $<$ | ✗ | ✗ | ✓ |
| $\subseteq$ | ✓ | ✗ | ✓ |
| $\perp$ | ✗ | ✓ | ✗ |
| $\parallel$ | — | ✓ | ✓ |

$\leq$ and $\subseteq$ fail symmetry, and that failure is exactly what makes them **orders** rather than equivalences (module 2.3).

Perpendicularity fails two: a line is not perpendicular to itself, and $\ell_1\perp\ell_2$ with $\ell_2\perp\ell_3$ gives $\ell_1\parallel\ell_3$ rather than $\ell_1\perp\ell_3$.

Parallelism is the interesting one. Whether it is reflexive depends on your book's definition: if parallel lines must be *distinct*, then $\ell\not\parallel\ell$ and it fails. Most texts define $\ell\parallel\ell$ to be true exactly to make parallelism an equivalence relation — a definition chosen to get a structural property, which is a thing definitions are allowed to do.

## Congruence is an equivalence relation

Module 3.9 proved the three properties for congruence of figures, using rigid motions:

| Property | Function fact |
|---|---|
| $F\cong F$ | the identity is a rigid motion |
| $F\cong G \Rightarrow G\cong F$ | rigid motions have inverses |
| $F\cong G,\ G\cong H \Rightarrow F\cong H$ | compositions of rigid motions are rigid motions |

**Your book states these as properties; Chapter 3 proved them.** Read the right-hand column again: identity, inverses, closure under composition. Those are the three facts about rigid motions, and they line up one-to-one with the three properties on the left.

That correspondence is not a coincidence. **Whenever a relation is defined by "some transformation of a fixed collection carries one thing to the other," it is automatically reflexive, symmetric, and transitive** — provided that collection contains an identity, contains an inverse for each of its members, and is closed under composition. Those three requirements are what produce the three properties, in that order.

## Splitting a set into parts

Here is what equivalence relations are *for*.

> **Theorem.** An equivalence relation on a set splits it into classes that never overlap, with every element in exactly one class. The other way round, every such splitting arises from an equivalence relation.

A division of a set into non-overlapping parts that use up everything is called a **partition**, and that is the word the courses ahead will use for it.

The classes are the groups of mutually related elements.

- Leaving the same remainder on division by $3$ splits $\mathbb{Z}$ into three groups — module 4.4's sorting by remainder.
- Congruence splits the triangles into classes of mutually congruent ones.
- Similarity splits them more coarsely: each similarity class contains many congruence classes, one for each size.
- Equality splits a set into singletons, the finest possible splitting.

**No overlaps, and nothing left out**, which is module 1.12's requirement for proof by cases. So every case argument that splits by remainder is licensed by this theorem, and the license comes from the three properties.

<Warning title="Transitivity needs a genuine middle">
From $\overline{AB}\cong\overline{CD}$ and $\overline{EF}\cong\overline{CD}$, concluding $\overline{AB}\cong\overline{EF}$ takes **two** steps: symmetry to turn the second into $\overline{CD}\cong\overline{EF}$, then transitivity.

Your two-column proofs often compress this, and the compression is where errors hide. The chain must genuinely link — the object ending the first relation must be the object starting the second.

The same care applies to $\leq$: from $a\leq b$ and $c \leq b$ nothing follows about $a$ and $c$, and no amount of rearranging will make it follow, because $\leq$ is not symmetric.
</Warning>

<Aside>
Equivalence relations are how mathematicians build new objects by declaring things equal.

The rational numbers are a case you have used without noticing. $\frac12$ and $\frac24$ are different pairs of integers and the same rational, because $\mathbb{Q}$ is defined as the set of pairs $(a,b)$ with $b\neq0$, under the sameness rule $(a,b)\sim(c,d)$ exactly when $ad = bc$. A rational number *is* a whole family of pairs, counted as one.

Module 4.5's remark that "$\frac12$ and $\frac24$ are the same number written two ways" was this theorem, unstated.

The same construction gives $\mathbb{Z}$ from $\mathbb{N}$, and $\mathbb{R}$ from $\mathbb{Q}$. Every number system you use is built by taking a simpler one and declaring some things equal — which makes this module's four axioms the toolkit underneath all of Chapter 4.
</Aside>
