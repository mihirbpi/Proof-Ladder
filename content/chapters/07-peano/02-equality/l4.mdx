## Axioms 1–4

For all $x, y, z$:

$$
\textbf{A1 (reflexivity)}\quad x = x
$$

*In words: everything equals itself; if one thing equals a second, the second equals the first; and equalities chain.*
$$
\textbf{A2 (symmetry)}\quad x = y \Rightarrow y = x
$$

*Symbol by symbol: $\Rightarrow$ is "forces". So the line reads: if $x$ equals $y$, then $y$ equals $x$.*

$$
\textbf{A3 (transitivity)}\quad (x=y \wedge y=z) \Rightarrow x = z
$$

*Symbol by symbol: $\Rightarrow$ is "forces", $\wedge$ is "and". So the line reads: if $x$ equals $y$ and $y$ equals $z$, then $x$ equals $z$.*

$$
\textbf{A4 (closure)}\quad (x \in \mathbb{N} \wedge x = y) \Rightarrow y \in \mathbb{N}
$$

*Symbol by symbol: $\mathbb{N}$ is the counting numbers, $\in$ is "is in", $\Rightarrow$ is "forces", $\wedge$ is "and". So the line reads: if $x$ is a counting number and $x$ equals $y$, then $y$ is a counting number too.*

A4 is the *substitution* property in miniature: equals may be substituted for equals in any statement, here specifically in membership claims. Without it, "equal" objects could differ in which sets they belong to, and every proof that rewrites one expression as an equal one would be unjustified.

## Equivalence relations

A relation $\sim$ on a set $S$ satisfying A1–A3 is an **equivalence relation**. Recall the move module 2.9 made, since it is easy to skim past: a relation on $S$ is not treated as a description but as the **collection of ordered pairs it holds for**. So $a \sim b$ is shorthand for *the pair $(a,b)$ is in that collection*. The reason for defining it that way is that two descriptions holding for exactly the same pairs can never be told apart by any proof — so the pairs are the only part that matters.

### Which relations qualify

| Relation | Refl. | Symm. | Trans. | Equivalence? |
|---|---|---|---|---|
| $=$ on any set | ✓ | ✓ | ✓ | yes |
| same remainder on division by $n$ | ✓ | ✓ | ✓ | yes |
| same cardinality (module 3.8) | ✓ | ✓ | ✓ | yes |
| $\leq$ on $\mathbb{R}$ | ✓ | ✗ | ✓ | no |
| $<$ on $\mathbb{R}$ | ✗ | ✗ | ✓ | no |
| $\subseteq$ (module 2.3) | ✓ | ✗ | ✓ | no |
| "is a friend of" | ✓? | ✓ | ✗ | no |
| $\perp$ (perpendicular) | ✗ | ✓ | ✗ | no |

### Relations that fail

Note that $\leq$ and $\subseteq$ satisfy two of the three and are **orderings** instead — reflexive, transitive, and *such that mutual containment forces equality*. Swapping symmetry for the rule that mutual containment forces equality gives an entirely different kind of structure, which is why the three properties must be checked individually.

## Same remainder

For $n \geq 1$, say that $a$ and $b$ **leave the same remainder on division by $n$** when $n \mid (a-b)$ (module 4.2). Later courses write this $a \equiv b \pmod n$ and call it *congruence modulo $n$*; the notation is theirs, the idea is the one you already have from long division.

<Proof>

*The symbols in this proof: $\equiv$ is "says the same as", $\in$ is "is in", $\mathbb{Z}$ is the integers, the bar $\mid$ is "divides". In words, what follows shows: having the same remainder passes all three tests, so it behaves like equality.*

**Reflexive.** $n \mid (a - a) = 0$ for every $n$, so $a \equiv a$.

**Symmetric.** If $n \mid (a-b)$, say $a - b = nk$, then $b - a = n(-k)$ with $-k \in \mathbb{Z}$, so $n \mid (b-a)$.

**Transitive.** If $a - b = nj$ and $b - c = nk$, then
$$a - c = (a-b)+(b-c) = n(j+k),$$
and $j+k \in \mathbb{Z}$ by closure. So $n \mid (a-c)$.
</Proof>

Each step is the divisibility template of module 4.3.

## Equivalence classes, and splitting a set into parts

For $a \in S$, the **equivalence class** of $a$ is
$$
[a] = \{\, x \in S \mid x \sim a \,\}.
$$

*Symbol by symbol: $\in$ is "is in", the bar $\mid$ is "such that". So the line reads: the class of $a$ is everything in $S$ that counts as the same as $a$.*

> **Theorem.** The equivalence classes of $\sim$ **partition** $S$ — that is, they divide it into parts with no overlaps and nothing left out: every element lies in exactly one class.

<Proof>

*The symbols in this proof: $\in$ is "is in", $\cap$ is "overlapped with", $\subseteq$ is "sits inside", $\emptyset$ is "the empty set". In words, what follows shows: the classes cover everything and never partly overlap — two are either identical or share nothing.*

*Every element is in a class.* $a \in [a]$ by reflexivity.

*Classes are identical or **disjoint** — sharing nothing at all.* Suppose $[a]\cap[b] \neq \emptyset$, say $c \in [a]\cap[b]$, so $c \sim a$ and $c \sim b$.

Let $x \in [a]$, so $x \sim a$. From $c \sim a$ and symmetry, $a \sim c$; with transitivity, $x \sim c$; with $c \sim b$ and transitivity again, $x \sim b$, so $x \in [b]$. So $[a]\subseteq[b]$, and by symmetry of the argument $[b]\subseteq[a]$. So $[a]=[b]$ by double inclusion (module 2.6).
</Proof>

All three axioms were used, each exactly once — a good demonstration that none is redundant.

For congruence mod $3$ the classes are
$$
[0] = \{\ldots,-3,0,3,6,\ldots\},\quad [1]=\{\ldots,1,4,7,\ldots\},\quad [2]=\{\ldots,2,5,8,\ldots\},
$$
which is exactly the division into parts that module 4.4 produced from the division algorithm. Two routes, one answer.

<Warning title="Well-definedness returns">
Defining operations on classes means checking the answer does not depend on which name you picked — the check module 3.1 introduced.

$[a]+[b] := [a+b]$ is well defined: if $a \equiv a'$ and $b\equiv b'$ then $n \mid (a-a')$ and $n\mid(b-b')$, so $n \mid (a+b)-(a'+b')$ and $[a+b]=[a'+b']$. ✓

the rule sending $[a]$ to $a$ is **not** well defined: $[1] = [4]$ mod $3$, and $1 \neq 4$. No one member of a class is the official one — there is no single standard choice fixed once and for all.

This check is required every time, and it is the step first-year algebra students skip most often.
</Warning>

<Aside>
Quotients by equivalence relations are how number systems get built. $\mathbb{Z}$ is pairs of naturals under $(a,b)\sim(c,d) \iff a+d = b+c$, with $(a,b)$ meaning $a - b$. $\mathbb{Q}$ is pairs of integers under $(p,q)\sim(r,s)\iff ps = qr$ (module 4.5). $\mathbb{Z}/n\mathbb{Z}$ is $\mathbb{Z}$ under congruence.

In each case: start with known objects, choose the right notion of *same*, and the classes are the new numbers.
</Aside>
