## The recursion

$$
\textbf{(M1)}\ \ a\cdot 0 = 0, \qquad\qquad \textbf{(M2)}\ \ a\cdot S(b) = a + (a\cdot b).
$$

Structurally identical to addition's recursion, one level up:

| Operation | Base | Step |
|---|---|---|
| $+$ | $a + 0 = a$ | $a + S(b) = S(a+b)$ |
| $\cdot$ | $a\cdot0 = 0$ | $a\cdot S(b) = a + (a\cdot b)$ |

Addition iterates $S$; multiplication iterates $+$. In each case the base is the identity element of the operation being iterated — $a$ for addition, $0$ for multiplication — and the step applies that operation once more.

Legitimacy again comes from the result quoted in module 7.6 — that a definition by recursion really does determine exactly one function — so A9 underwrites this definition too.

## Derivations

<Proof>
$$
3\cdot2 = 3\cdot S(1) = 3 + (3\cdot1) = 3 + \big(3 + (3\cdot 0)\big) = 3 + (3+0) = 3+3 = 6.
$$
</Proof>

> **Proposition.** $a \cdot 1 = a$.

<Proof>
$$
\begin{aligned}
a\cdot 1 &= a\cdot S(0)   && \text{since } 1 = S(0)\\
         &= a + (a\cdot0) && \text{by the second multiplication rule}\\
         &= a + 0         && \text{by the first multiplication rule}\\
         &= a             && \text{by the first addition rule}
\end{aligned}
$$
</Proof>

The proof consumed both definitions, which is the tower doing its work.

## The distributive law is a theorem

Module 4.1 presented distributivity as an axiom of $\mathbb{Z}$ — a rule to be accepted. Over $\mathbb{N}$ it is derivable.

> **Theorem.** $a\cdot(b+c) = a\cdot b + a\cdot c$.

**It is provable from here, and the shape is worth seeing even without the full derivation.**

Induct on $c$. The choice of $c$ is forced: the second multiplication rule peels the second slot of $\cdot$, and the second addition rule peels the second slot of $+$, so $c$ is the slot both definitions can reach.

At $c = 0$ both sides come to $a\cdot b$, one by the first addition rule and the other by the first multiplication rule.

For the step, assume the identity holds at $k$ and push to $S(k)$. The two defining rules move you from $a\cdot(b+S(k))$ to $a + a\cdot(b+k)$; the assumption rewrites that as $a + (a\cdot b + a\cdot k)$; and then the terms have to be **reordered** to reach $a\cdot b + a\cdot S(k)$.

That reordering is the interesting step, because it is not free. It spends the commutativity and associativity of addition — which module 7.6 had to prove by three separate inductions. Without those, the rearrangement would be unjustified, and the whole derivation would stall there.

## The rest

By similar inductions, all requiring distributivity as input:

$$
a \cdot b = b\cdot a, \qquad (a\cdot b)\cdot c = a\cdot(b\cdot c), \qquad a \cdot 0 = 0 = 0 \cdot a.
$$

So the counting numbers obey every arithmetic law of module 4.1 except the one giving negatives, and every algebraic law used since Chapter 4 is now a theorem.

<Aside>
The pattern iterates: exponentiation is $a^0 = 1$, $a^{S(b)} = a\cdot a^b$ — repeated multiplication, same shape again.

Continuing the pattern — each operation being the previous one repeated — gives a tower of ever faster-growing operations. Growth becomes explosive almost immediately: the fourth level already produces towers of exponents too large to write, and running diagonally down the whole hierarchy gives a rule that a computer could follow in principle, yet one that outruns every level of the tower it came from.

So the innocuous move "iterate the previous operation" generates, in five steps, functions that outgrow every recursion scheme this chapter has used.
</Aside>
