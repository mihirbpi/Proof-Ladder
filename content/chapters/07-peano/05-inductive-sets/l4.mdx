## The gap A5–A8 leave

$$
\mathbb{N}' = \{0,1,2,\ldots\}\ \cup\ \{a,b\}, \qquad S(a)=b,\ S(b)=a,
$$

*Symbol by symbol: $\mathbb{N}$ is the counting numbers, $\cup$ is "pooled with". So the line reads: the ordinary counting numbers together with two extra items that point at each other forever.*
with the standard successor on the numerals, satisfies A5–A8 (module 7.4). The elements $a,b$ lie outside the orbit of $0$ and are unreachable from it.

A5–A8 constrain only what $\mathbb{N}$ must **contain**; nothing yet forbids extra components. The final axiom is a **smallest-possible** condition.

## Inductive sets

> $V$ is **inductive** if $0 \in V$ and $\forall x\,(x\in V \Rightarrow S(x)\in V)$.

$$
\textbf{A9}\quad V \text{ inductive} \Rightarrow \mathbb{N}\subseteq V.
$$

*Symbol by symbol: $\mathbb{N}$ is the counting numbers, $\subseteq$ is "sits inside", $\Rightarrow$ is "forces". So the line reads: any collection holding zero and closed under "next" already holds every counting number.*

So $\mathbb{N}$ is contained in every inductive set: it is the *smallest* one.

The definition is worth reading slowly, because it packs the whole domino picture into two conditions. An inductive set is one you cannot fall out of by counting: it holds $0$, and it never lets go of a successor. A9 then says $\mathbb{N}$ has nothing in it beyond what those two conditions force you to keep.

Note that inductive sets are usually much larger than $\mathbb{N}$. Every set containing all the numerals plus anything else at all is still inductive, provided the extras are closed under $S$. A9 does not claim $\mathbb{N}$ is the only one — only that it sits inside all of them.

## Excluding the rogues

<Proof>
In $\mathbb{N}'$ above, let $V = \{0,1,2,3,\ldots\}$, the orbit of $0$ under $S$.

$V$ is inductive: $0 \in V$, and if $x \in V$ then $x = S^m(0)$ for some $m$, so $S(x) = S^{m+1}(0)\in V$.

By A9, $\mathbb{N}\subseteq V$. Since $a \notin V$, we get $a \notin\mathbb{N}$, and likewise $b \notin \mathbb{N}$.
</Proof>

Combining with module 7.4:

$$
\{0,1,2,\ldots\}\subseteq \mathbb{N} \quad\text{(A5, A6)}, \qquad
\mathbb{N}\subseteq\{0,1,2,\ldots\} \quad\text{(A9)},
$$

*Symbol by symbol: $\mathbb{N}$ is the counting numbers, $\subseteq$ is "sits inside". So the line reads: each sits inside the other, so the two are the same collection — the double-inclusion move of §2.6.*

$$
\therefore\quad \mathbb{N} = \{0,1,2,3,\ldots\}.
$$

*Symbol by symbol: $\mathbb{N}$ is the counting numbers. So the line reads: so the counting numbers are exactly $0$ and everything you reach by stepping up from it.*

A set equality established by **double inclusion** (module 2.6) — the two directions coming from opposite ends of the axiom list.

## A9 *is* induction

Rewrite A9 with $V = \{n \in \mathbb{N} : A(n)\}$ for a statement $A$:

| Inductive set condition | Induction |
|---|---|
| $0 \in V$ | base case $A(0)$ |
| $x \in V \Rightarrow S(x)\in V$ | inductive step $A(k)\Rightarrow A(S(k))$ |
| $\mathbb{N}\subseteq V$ | $A(n)$ for all $n$ |

They are the same statement. **Chapter 6's proof technique is Chapter 7's ninth axiom.**

This resolves a question left open in module 6.1: induction cannot be proved from more basic facts about $\mathbb{N}$, because it is one of the facts that define $\mathbb{N}$.

<Aside>
This also explains why induction feels like it should need justifying and never gets any.

The domino argument of module 6.1 is not a proof of induction; it is a picture of what the axiom asserts. Asking why the dominoes all fall is asking why $\mathbb{N}$ has no rogue elements sitting off the chain — and the answer is that we declared it so, because a number system with rogue elements is not the one we meant to describe.
</Aside>

<Warning title="Induction is genuinely independent">
Module 7.4's rogue model satisfies A5–A8 and **violates** A9: there $V = \{0,1,2,\ldots\}$ is inductive but does not contain $a$.

By the model method (module 7.1), no derivation of A9 from A5–A8 exists. Induction is an axiom, not a theorem.
</Warning>

## Equivalent forms

Given A5–A8, the following are equivalent:

- **A9** (induction): every inductive set contains $\mathbb{N}$.
- **The smallest-number principle:** every nonempty subset of $\mathbb{N}$ has a smallest member.
- **Strong induction:** if $A(m)$ for all $m<k$ implies $A(k)$, then $A$ holds throughout.
- **No infinite descent:** there is no strictly decreasing infinite sequence in $\mathbb{N}$.

Module 6.2 proved induction $\Rightarrow$ the smallest-number principle; module 6.4 proved strong induction $\Leftrightarrow$ induction. Module 4.4's division algorithm used the smallest-number principle, and module 4.7's irrationality proof can be written either with lowest terms or with descent — so several arguments in this course were quietly using A9 in disguise.

## The nine axioms

| # | Statement |
|---|---|
| 1–3 | $=$ is reflexive, symmetric, transitive |
| 4 | equals belong to the same sets |
| 5 | $0 \in \mathbb{N}$ |
| 6 | $x\in\mathbb{N}\Rightarrow S(x)\in\mathbb{N}$ |
| 7 | $S(x)\neq 0$ |
| 8 | $S$ is injective |
| 9 | induction |

That is the entire foundation. Modules 7.6 and 7.7 build addition and multiplication on it, and everything else in arithmetic follows.

<Aside>
A9 talks about **collections** $V$, not about individual numbers, and that is where its strength comes from: it says something about every collection at once, and there are a great many collections. Taken together, A5–A9 pin the counting numbers down completely — any system obeying all of them is the counting numbers with different names on the objects.

Weaken A9 so that it speaks only about collections you can *describe with a formula*, and the pinning-down fails. Systems then exist that obey every axiom and still contain objects bigger than every ordinary number. Which is startling, and is a story for much later; the point to carry now is that A9 is the axiom doing the heavy lifting.
</Aside>
